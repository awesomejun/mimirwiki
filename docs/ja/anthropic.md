# Anthropic

> Anthropic, PBCはカリフォルニア州サンフランシスコに本社を置くデラウェア州のパブリック・ベネフィット・コーポレーションであり、人工知能の安全性研究とClaude AIモデルの開発を目的として2021年に設立された。そのガバナンス構造は、Class T株式を通じて取締役会の過半数を選任する長期利益信託（LTBT）と、Founder LLCが保有するClass F議決権株式を組み合わせている。Anthropicは2026年11月、1株当たり83.00ドルでティッカーシンボルANTとしてNasdaqへのIPOを完了した。

Anthropic, PBCは、米国デラウェア州にパブリック・ベネフィット・コーポレーション（Public Benefit Corporation）として設立され、カリフォルニア州サンフランシスコに本社を置く人工知能の安全性および研究企業である。2021年にDario Amodei、Daniela Amodei、および他の5名の共同創業者によって設立され、人類の長期的利益のために高度なAIを責任を持って開発・維持するという定款上の目的のもと、Claudeファミリーの人工知能モデルおよび関連する開発者向けツールを開発している。そのガバナンス構造は、パブリック・ベネフィット・コーポレーションとしての地位に加え、取締役会の過半数を選任する権限を持つClass T普通株式を保有する独立したデラウェア州目的信託である長期利益信託（Long-Term Benefit Trust）と、一般株主議決権の50.1%を有するFounder LLCのClass F普通株式を組み合わせている。Anthropicは2026年11月にNasdaq Global Select MarketへティッカーシンボルANTで新規株式公開（IPO）を完了し、引受会社オプションの全面行使を含むClass A株式11億2,700万株を1株当たり83.00ドルで販売したほか、260億ドル規模のClass N株式の同時私募増資を実施した。

## Anthropicの公益ガバナンスと株式構造

Anthropic, PBCはデラウェア州法のもとでパブリック・ベネフィット・コーポレーション（Public Benefit Corporation）として設立されており、人類の長期的利益のために高度なAIを責任を持って開発・維持することを定款上の目的として掲げている。[2][4][12] デラウェア州のパブリック・ベネフィット・コーポレーション法に基づき、Anthropicは株主の金銭的利益、自社の行動によって重大な影響を受ける人々の最善の利益、および修正・再規定された基本定款に明記された特定の公益目的の均衡を図る義務を負う。[2][4][12]

この法人形態に取締役会監督機能を組み合わせるため、Anthropicは2023年9月19日に長期利益信託（Long-Term Benefit Trust、LTBT）を発表した。[4] LTBTはAnthropicと同一の目的を有するデラウェア州コモンロー上の目的信託として組成されており、AI安全性、国家安全保障、公共政策、社会的企業の専門知識を備え、財務的な利害関係のない5名の受託者から成る独立機関として構成されている。[2][4][12] Anthropicは、日常的な事業戦略を経営陣が担う一方、LTBTはモデルの破滅的リスクの評価や高水準のセキュリティ維持といった長期的課題に取り組むことを想定していると述べている。[4] 2026-11-23時点で、Anthropicの企業ページにはBen Bernanke博士、Richard Fontaine、Neil Buddy Shah、および2026年10月21日に就任したChristopher Stubbs博士の4名がLTBT受託者として記載されている。[3][4][14]

AnthropicのForm 424B4最終目論見書は、5種類の授権普通株式（Class A、Class N、Class F、Class T、Class E）を詳述しており、AnthropicがNasdaq Global Select Marketのコーポレートガバナンス要件上の支配企業（controlled company）に該当することを明記している。[12] 以下の表は、Form 424B4、Form S-1/A-3、およびLTBT発表文書に記載された各株式の議決権、経済的権利、および転換条件をまとめたものである。[2][4][12]

| 普通株式の種類 | 文書化されたガバナンス、議決権、および経済的権利 |
| --- | --- |
| Class A普通株式 | 1株当たり1議決権、転換不可、Nasdaq Global Select MarketにティッカーANTで上場 |
| Class N普通株式 | Class Aと同一の経済的権利を持つが、法令上必要な場合を除き議決権なし。主に戦略的パートナー（260億ドルのIPO同時私募増資を含む）およびAnthropic Public Benefit Fund, LLCが保有し、非関連第三者への売却・譲渡時に原則としてClass Aへ転換される |

2026年10月18日に発表されForm S-1/A-3に詳述された公益イニシアティブの一環として、Anthropicは2026年6月30日時点の完全希薄化後株式数（Amazon Notesの全額転換を前提）の5%に相当するClass N普通株式8億4,684万960株を、同社の目的に専念する完全子会社Anthropic Public Benefit Fund, LLCへ拠出した。[2][14] さらにAnthropicの取締役会は、IPO価格を起点として株価が前回の基準値から50%上昇するごとに、その時点の発行済株式数（オプション、制限付株式ユニット、その他の転換証券の対象株式および同基金が保有する株式を含む）の最大2%を追加で同基金（または他の指定先）へClass N普通株式として発行できる裁量枠組みを承認した。[2] これとは別に、Anthropicの各共同創業者は、個人として保有するAnthropic株式の80%を慈善活動に充てることを誓約した。[2]

## AnthropicのConstitutional AIと安全性研究

Anthropicは研究、政策、製品、運営の4つの事業領域に組織を分けており、解釈可能性（interpretability）、アライメント（alignment）、および人工知能の経済的・社会的影響に関する技術研究を実施している。[3] 同社は、信頼性が高く、解釈可能で、制御可能（steerable）なAIシステムを構築し、研究成果を製品へ応用するとともに研究結果を公表することを技術的目標として掲げている。[3]

2022年12月15日、AnthropicのYuntao BaiとSaurav Kadavath、Sandipan Kundu、Amanda Askell、Dario Amodei、Jared Kaplanを含む50名の共著者は、論文「Constitutional AI: Harmlessness from AI Feedback」（arXiv:2212.08073）を提出した。[7] Constitutional AI（憲法的AI）は、有害な出力を識別する人間によるラベル付けを用いず、明文化された規則や原則のリストのみを無害性に関する唯一の人間の監督手段として、自己改善を通じて無害なAIアシスタントを訓練する手法である。[7]

- 教師あり学習段階：初期モデルから応答をサンプリングし、明文化された原則に沿って自己批評と修正を生成させたうえで、修正後の応答を用いて元のモデルをファインチューニングする。[7]
- 強化学習段階（AIフィードバックによる強化学習、Reinforcement Learning from AI Feedback、RLAIF）：ファインチューニング後のモデルから応答ペアをサンプリングし、どちらの応答が原則をよりよく満たすかをAIモデルに評価させてAI選好データセットを構築する。このデータセットで選好モデルを訓練し、その選好モデルを報酬信号として強化学習によりアシスタントを訓練する。[7]

同論文によると、教師あり学習と強化学習の両段階において思考の連鎖（chain-of-thought）推論を活用することで、人間が評価する性能とAIの意思決定における透明性を向上させることができ、はるかに少ない人間ラベルで有害な問い合わせに対し異議の理由を説明しながら対応するアシスタントを生み出せる。[7]

## Anthropicの責任あるスケーリングポリシー

Anthropicは、高度なAIシステムによる破滅的リスクに対処するための自主的なリスクガバナンス枠組みとして、2023年9月19日に初めて発効した責任あるスケーリングポリシー（Responsible Scaling Policy、RSP）を運用している。[6] AnthropicのRSPページの2026年8月14日更新時点において、同ポリシーは2026年7月8日発効のバージョン3.4となっている。[6]

RSPのもとでは、所定の能力閾値に達した場合、2024年10月15日のバージョン2.0とあわせて概要が示されたASL-3セキュリティ標準およびASL-3展開標準など、より高水準の安全対策基準へモデル保護を引き上げることが求められる。[6] 計画されたASL-3展開安全対策は、化学・生物・放射性物質・核（CBRN）能力の悪用可能性に対処するため、個別の安全対策を必要とするパートナー向けの強化デューデリジェンスを伴うアクセス制御、オンライン介入を備えたリアルタイムのプロンプトおよび出力分類器、非同期監視分類器、ならびに迅速な対応手順を伴う事後ジェイルブレイク検出の4層で構成される。[6]

## Anthropicの製品、オープンソースソフトウェア、およびModel Context Protocol

Anthropicは、[Claude](https://mimirwiki.com/ja/wiki/claude)ファミリーのAIモデルおよび関連ソフトウェア製品を通じて研究成果を提供しており、これにはClaude.ai、Claudeコンソール、Claude Developer Platform、Claude Desktopアプリ、Claude for Work、Claude Code、およびClaude Coworkが含まれる。[3][5][8][9] 2026年11月までのAnthropicの発表および一次開示において確認される公開モデルには、Claude 3ファミリー、Claude 3.5 Sonnet、Claude Opus 4.5および4.6、Claude MythosおよびFable 5.1（2026年9月15日）、Claude Opus 5.5（2026年9月22日）、Claude Sonnet 5.5（2026年9月28日）、Claude Haiku 5.5（2026年10月7日）、ならびに[Claude Fable 5.2](https://mimirwiki.com/ja/wiki/claude-fable-5-2)およびClaude Mythos 5.2（2026年11月9日）がある。[5][6][10][14]

2024年11月25日、Anthropicは所属エンジニアのDavid Soria ParraとJustin Spahr-Summersが同社で開発した[Model Context Protocol](https://mimirwiki.com/ja/wiki/model-context-protocol)（MCP）をオープンソース化した。MCPはAIアシスタントとコンテンツリポジトリ、業務ツール、開発環境といったデータソースとの双方向接続を実現するオープン標準である。[5] MCPは、データソースを公開するMCPサーバーと、AIアプリケーション内部からそれらのサーバーに接続するMCPクライアントから成るアーキテクチャを定義している。[5] さらに2026年8月27日、Anthropicは科学実験室や先端製造現場においてAIエージェントが物理デバイスを安全に操作するための共通仕様であるModel Hardware Standard（MHS）のリサーチプレビューも公開した。[14]

2025年12月9日、AnthropicはBlockのgooseフレームワークおよび[OpenAI](https://mimirwiki.com/ja/wiki/openai)のAGENTS.md規約と並び、Linux Foundation傘下のAgentic AI Foundation（AAIF）へ創設プロジェクトとしてMCPを寄贈した。[8] AnthropicはAmazon Web Services、Block、Bloomberg、[Cloudflare](https://mimirwiki.com/ja/wiki/cloudflare)、Google、Microsoft、OpenAIとともにプラチナメンバーとしてAAIFに参加した。[8] 2025年12月9日時点で、Linux Foundationは公開済みMCPサーバーが10,000件を超え、[Claude](https://mimirwiki.com/ja/wiki/claude)、[Cursor](https://mimirwiki.com/ja/wiki/cursor)、[Microsoft Copilot](https://mimirwiki.com/ja/wiki/microsoft-copilot)、[Google Gemini](https://mimirwiki.com/ja/wiki/google-gemini)、VS Code、および[ChatGPT](https://mimirwiki.com/ja/wiki/chatgpt)で採用されていると報告した。[8]

2026-11-23時点で、`anthropic.com`ドメインの認証を受けたAnthropicのGitHub組織（`anthropics`）には118件の公開リポジトリと99.9k人のフォロワーが存在し、主要言語にはPython、Rust、Go、TypeScript、C++が含まれる。[9] 同組織の概要ページに掲載されている公開リポジトリには、`skills`（Agent Skills、スター数約199,000）、`claude-code`（ターミナルベースのエージェント型コーディングツール、スター数156,772）、`claude-cookbooks`（スター数約55,100）、`claude-plugins-official`（スター数48,023、Apache-2.0）、`financial-services`（スター数約41,500）、`prompt-eng-interactive-tutorial`（スター数約39,700）、`knowledge-work-plugins`（Claude Cowork向けオープンソースプラグイン、スター数36,731、Apache-2.0）、`claude-for-legal`（スター数10,075、Apache-2.0）、および`claude-code-action`（スター数10,055、MIT）がある。[9]

2026年11月25日、Anthropicは2024年初頭から2026年秋にかけてAPIトラフィックが約1,800倍に増加したことを受け、外部顧客やClaude Code・Coworkが利用するMessages APIをPythonからRustへ移行した技術報告を公開した。[16][17] 本番リクエストを旧Python実装と新Rust実装で比較検証した結果、同社自社計測でリクエスト当たりCPU使用量が約70%減少し、初回トークン到達時間の中央値が約20%短縮されたと報告しているが、独立再現や全応答完了時間の変化は未確認である。[16]

## Anthropicのクラウドインフラストラクチャと戦略的投資

AnthropicはAmazonと戦略的提携および少数株主出資契約を締結しており、Amazonは2024年3月27日にAnthropicに対する総額40億ドルの出資を完了した。[10] Amazonは2023年9月に12億5,000万ドルの初回出資を行い、2024年3月27日に27億5,000万ドルを追加出資して少数持分を取得した。[10] また、2026年11月17日に提出されたAnthropicのForm S-1/A-3では、2026年6月30日時点の完全希薄化後株式数を報告するにあたり、Amazon Notesと呼ばれる転換証券に言及している。[2]

Amazonが公表した戦略的契約に基づき、Anthropicは安全性研究や将来の基盤モデル開発を含む中核ワークロードの主要クラウドプロバイダーとしてAmazon Web Services（AWS）を利用し、将来のモデルの構築・訓練・展開にAWS TrainiumおよびInferentiaチップを使用することを約束した。[10] またAnthropicは、2024年3月にClaude 3モデルファミリーが提供開始されたAmazon Bedrock上で、AWS顧客が将来の世代の基盤モデルを利用できるようにする長期的コミットメントを結んだ。[10] このクラウド提携と並行して、AWS、Anthropic、およびAccentureは、ヘルスケア、公共部門、銀行、保険といった規制産業におけるエンタープライズ向け生成AI導入を支援する共同取り組みを発表した。[10]

2026年11月のIPOにおいて、AnthropicはAdvanced Micro Devices, Inc.、Broadcom Inc.、Google LLC（Google 2026 NPAに基づき以前から約定していた出資義務の一部を履行）、Micron Technology, Inc.、Microsoft Corporation、[NVIDIA](https://mimirwiki.com/ja/wiki/nvidia) Corporation、およびTSMC Partners, Ltd.に対し、Class N株式3億1,325万3,007株を1株当たり83.00ドルで発行する総額260億ドルの同時私募増資を通じて、戦略的資本および計算資源エコシステムの関係を拡大した。[11][12] この同時私募増資は、IPOとあわせて2026年11月20日に完了した。[14]

## よくある質問

### Anthropicはどのような法人形態ですか？

Anthropic, PBCはデラウェア州のパブリック・ベネフィット・コーポレーション（Public Benefit Corporation）であり、米国証券取引委員会（SEC）にCIK 0002130357として登録されています。デラウェア州法に基づき、取締役会は株主の財務的利益、事業活動によって重大な影響を受ける関係者の最善の利益、および人類の長期的利益のために高度なAIを責任を持って開発・維持するという定款上の目的の均衡を図ります。 [1][2][12]

### 2026年11月のAnthropicのIPOの条件と結果はどうでしたか？

Anthropicは2026年11月18日、Goldman Sachs & Co. LLCおよびMorgan Stanley & Co. LLCを主幹事として、Class A普通株式の基本売出・発行分9億8,000万株の公開価格を1株当たり83.00ドル（基本総額813億4,000万ドル）に決定しました。株式は2026年11月19日にNasdaq Global Select MarketでティッカーシンボルANTとして取引を開始し、The Guardianによると初日の終値は97ドルをわずかに上回りました。2026年11月20日には、引受会社による1億4,700万株のオプション全面行使を含め計11億2,700万株のClass A株式をもってIPOを完了し、あわせて260億ドル規模のClass N株式の同時私募増資も完了しました。 [11][12][13][14][15]

### Anthropicの長期利益信託（LTBT）とは何ですか？

長期利益信託（Long-Term Benefit Trust、LTBT）は、AI安全性、国家安全保障、公共政策、社会的企業の分野で経歴を持ち、財務的な利害関係のない受託者で構成される独立したデラウェア州目的信託です。経済的権利や一般株主議決権を持たないClass T普通株式を通じて、LTBTはAnthropicの取締役会の過半数を選任・解任する権限を有しています。2026-11-23時点で、Anthropicの企業ページにはBen Bernanke博士、Richard Fontaine、Neil Buddy Shah、およびChristopher Stubbs博士が受託者として掲載されています。 [2][3][4][12]

### AnthropicのConstitutional AI訓練手法はどのように機能しますか？

2022年12月15日にAnthropicのYuntao Baiと共著者らが発表した研究論文で導入されたConstitutional AI（憲法的AI）は、有害な出力を識別する人間によるラベル付けを用いずに、明文化された規則や原則のリストを使用して無害なAIアシスタントを訓練する手法です。このプロセスは、モデル自身が生成した自己批評と修正に基づく教師ありファインチューニングと、それに続いてAIが評価した応答ペアで訓練された選好モデルを用いるAIフィードバックによる強化学習（RLAIF）の2段階で構成されます。 [7]

### Anthropicの責任あるスケーリングポリシー（RSP）とは何ですか？

Anthropicの責任あるスケーリングポリシー（Responsible Scaling Policy、RSP）は、高度なAIシステムによる破滅的リスクに対処するため、2023年9月19日に初めて発効した自主的なリスクガバナンス枠組みであり、能力の閾値と必要なセキュリティおよび展開上の安全対策を連動させています。2026年8月14日時点ではバージョン3.4（2026年7月8日発効）となっており、公開されるフロンティア安全性ロードマップ（Frontier Safety Roadmaps）、編集済みリスク報告書（Redacted Risk Reports）、および外部レビュー担当者に対するLTBTの審査権限が含まれています。 [6]

### Model Context Protocol（MCP）におけるAnthropicの役割は何ですか？

Anthropicは所属エンジニアのDavid Soria ParraとJustin Spahr-Summersを通じてModel Context Protocol（MCP）を開発し、AIアシスタントを外部データソースやツールと接続するための標準規格として2024年11月25日にオープンソース化しました。2025年12月9日には、Linux Foundation傘下のAgentic AI Foundation（AAIF）に創設プロジェクトとしてMCPを寄贈し、Anthropicは同財団のプラチナメンバーとなっています。 [5][8]
