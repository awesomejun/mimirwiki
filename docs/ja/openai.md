# OpenAI

> 2015年に非営利団体として設立され、2025年10月28日に非営利のOpenAI Foundationが営利法人のOpenAI Group PBCを支配する体制へ再編されたOpenAIは、GPT-6.2 AstraやSol、ChatGPT、CodexなどのフロンティアAIモデルを開発している。資本再編完了時点での持分比率は、OpenAI Foundationが26%（評価額約1,300億ドルおよび15年満期の業績連動ワラント）、Microsoftが約27%、従業員および投資家が47%であり、FoundationがGroupの全取締役を任命するとともに、医療分野のブレークスルーとAIレジリエンスに向けて初期250億ドルを拠出する方針を表明している。

OpenAIは、汎用人工知能（AGI）が全人類に恩恵をもたらすことを確実にするという使命を掲げ、2015年に米国サンフランシスコで設立された人工知能の研究・展開機関である。2025年10月28日に発表された構造的な資本再編を経て、OpenAIは非営利法人のOpenAI Foundationと、その支配下にある営利子会社のOpenAI Group PBC（公益法人）を通じて事業を運営しており、ChatGPTプラットフォーム、Codex、ならびにGPT-6、GPT-5、GPT-Image、GPT-Live、およびオープンウェイトのgpt-ossモデル群を開発している。

## OpenAIの歴史、AGIの使命、およびOpenAI憲章

OpenAIは2015年、OpenAI憲章において「経済的価値のあるほとんどの業務で人間を上回る高度に自律的なシステム」と定義される汎用人工知能（AGI）が全人類に恩恵をもたらすことを確実にするため、非営利の研究機関として設立された。[2][4] 公式GitHub組織アカウント（`github.com/openai`）は2015年10月3日に開設され、2026年後半時点で280の公開リポジトリをホストしている。[8] 2019年、OpenAIは資金調達および大規模な計算資源を要するモデルの学習・展開を拡大するため、元の非営利法人の取締役会が支配する営利子会社を設立した。[2]

OpenAI憲章（OpenAI Charter）は、同組織の活動を規定する4つの基本運営原則を明文化している。[4]

1. **広く分配される恩恵（Broadly Distributed Benefits）**: OpenAIは、AGIの展開に関して得るいかなる影響力も広く人類の利益のために行使し、人類に害を及ぼす用途や権力の過度な集中を避け、利害関係者間の利益相反を最小限に抑えながら、人類に対する受託者責任を最優先とすることを約束している。[4] 2. **長期的な安全性（Long-Term Safety）**: OpenAIは安全性・アライメント研究の実施と共有を約束するとともに、開発後期における「競争を停止し支援に転じる」条項を設けている。価値観が整合し安全性を重視する外部プロジェクトがOpenAIより先にAGIの構築に近づいた場合（通常、今後2年以内に成功する確率が50%を超える状態と定義される）、OpenAIは競争を中止し、そのプロジェクトを支援することを誓約している。[4] 3. **技術的リーダーシップ（Technical Leadership）**: AI能力の最前線に立たなければ政策提言や安全性の啓発だけでは不十分であるという考えに基づき、OpenAIは自らの使命に直接沿ったAGI到達前の技術能力において先導的立場を目指すとしている。[4] 4. **協調的志向（Cooperative Orientation）**: OpenAIは外部の研究機関や政策機関と協力し公共財を提供することを約束する一方で、セキュリティおよび安全性への配慮から、従来のオープンな能力公開から安全性・政策・標準研究の共有へと成果発表の比重が段階的に移行することを認めている。[4]

## 2025年のOpenAIのPBC資本再編、取締役会ガバナンス、および所有構造

2025年10月28日、カリフォルニア州およびデラウェア州の司法長官室との約1年間にわたる公式協議を経て、OpenAIは非営利法人による商業事業体の支配を維持しつつ企業構造を簡素化する包括的な資本再編を完了した。[2][3]

- **OpenAI Foundation（支配非営利法人）**: 親法人である501(c)(3)非営利団体はOpenAI Foundationへと改称された。[2][3] 独占的な特別議決権およびガバナンス権を保有するOpenAI Foundationは、営利法人の取締役会の全取締役を任命し、いつでも任意の取締役を交代させる単独権限を保持している。[2]
- **OpenAI Group PBC（支配下の公益法人）**: 営利子会社はOpenAI Group PBCという名称のデラウェア州公益法人（Public Benefit Corporation）へ転換され、商業的成長と並行してOpenAI Foundationと同一の使命を推進し、すべてのステークホルダーの広範な利益を考慮する法的義務を負うこととなった。[2][3]

取締役会の全会一致で承認された資本再編条件に基づき、従来の複雑な利益上限付き持分ユニットはすべて、企業価値の成長に比例して参加するOpenAI Group PBCの通常の普通株式へと転換された。[2]

| 株主区分 | 資本再編完了時点の持分比率 | 評価額・条件および権利 |
| --- | --- | --- |
| OpenAI Foundation（非営利法人） | 26%＋業績連動ワラント | 完了時点の評価額は約1,300億ドル（全体の企業価値は約5,000億ドル相当）、さらに株価が10倍超に上昇した場合に大規模な追加持分を付与する15年満期ワラントを保有 |
| Microsoft Corporation | 約27% | Microsoftの2026会計年度Form 10-Kに開示された複数年のクラウドおよび知的財産契約に基づく長期戦略的パートナー |
| 現職・元従業員および投資家 | 約47% | 通常の比例配分型普通株式 |

約1,300億ドルの初期株式価値を得たOpenAI Foundationは、従来の5,000万ドル規模のPeople-First AI Fundを拡充する形で、2つの柱に焦点を当てた初期250億ドルの公益拠出コミットメントを立ち上げた。1つ目は医療分野のブレークスルー加速と疾患治療（オープンソースのフロンティア医療データセットや科学研究助成を含む）、2つ目はAIレジリエンスのための技術的ソリューション構築（電力網、病院、金融システム、重要インフラをAI関連リスクから保護する取り組み）である。[3]

OpenAI Foundationは、議長のブレット・テイラー、CEOのサム・アルトマン、アダム・ダンジェロ、ポール・クリスティアーノ、スー・デスモンド＝ヘルマン博士、ジコ・コルター博士、ポール・M・ナカソネ元米陸軍大将、アデバヨ・オグンレシ、ニコール・セリグマン、デイビッド・ベレス、ロビン・ビンスの11名から成る取締役会によって統治されている。[2] ガバナンスの分断を防ぎつつ独立した安全監督を維持するため、安全・セキュリティ委員会（Safety and Security Committee、SSC）は引き続きOpenAI Foundationの常設委員会として、FoundationとOpenAI Group PBC双方のあらゆる安全実務を監督する。[2] SSC委員長のジコ・コルター博士はOpenAI Foundation取締役会でのみ議決権を有する取締役を務め、OpenAI Group PBC取締役会には無議決権のオブザーバーとしてのみ参加する（また、資本再編から1年以内に2人目のFoundation取締役もFoundation専任の議決権取締役兼Group無議決権オブザーバーへ移行する予定である）。[2]

## OpenAIのモデルラインナップと製品エコシステム（GPT-6.2世代）

2026年11月時点で、OpenAIのAPIおよび製品カタログは天体名の階層を採用したGPT-6およびGPT-6.2モデルシリーズ（`Astra`、`Sol`、`Terra`、`Luna`）を中核としており、主にResponses APIおよび公式クライアントSDKを通じて、特化型マルチモーダル、音声、ライフサイエンス、オープンウェイトの各モデルとともに提供されている。[5][6]

- **GPT-6.2およびGPT-6推論・エージェントシリーズ**: 複雑なエンドツーエンドのプロジェクトおよびフロンティアコーディング向けに2026年11月17日にリリースされた`gpt-6.2-astra`と、日常的なコーディングおよびエージェントのスケーリング向けの`gpt-6.2-sol`を筆頭に、`gpt-6.1-sol`、`gpt-6.1-terra`（高速な視覚推論、コンピュータ操作、自然な文章作成）、`gpt-6-astra`、`gpt-6-sol`、および超低コスト・大量処理向けの`gpt-6-luna`がラインナップされている。[5][6] 現行のすべての主力テキストモデルはテキストおよび画像入力を受け付けてテキストを出力し、30分および12時間のキャッシュ書き込み保持オプションを備えた設定可能なコンテキストキャッシュに対応している。[5][6]
- **ドメイン特化型フロンティアモデル**: OpenAIはアクセス制限付きのドメイン特化モデルを運用しており、認可された脆弱性調査・再現・パッチ検証向けの`gpt-6-cyber`および`gpt-5.6-cyber`、ならびに承認された研究機関向けにライフサイエンスおよび創薬化学の推論を提供する`gpt-rosalind-research`（GPT-Rosalind）がある。[6]
- **旧世代およびオープンウェイトモデル**: カタログには`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`、`gpt-5.5`および`gpt-5.5-pro`、`gpt-5.4`（`pro`、`mini`、`nano`）、`gpt-5.2`（`pro`）、`gpt-5.1`、`gpt-5`、`gpt-4.1`、`gpt-4o`、`o3`/`o3-pro`が残されているほか、2つのオープンウェイトモデルとして、単一のNVIDIA H100 GPUに収まるよう設計された`gpt-oss-120b`と、中規模・低遅延のオープンウェイトモデル`gpt-oss-20b`が提供されている。[5][6]
- **画像・音声・リアルタイムマルチモーダルモデル**: 画像生成は`gpt-image-2.6-sunburst`、`gpt-image-2.6-flare`、`gpt-image-2.5-sunburst`、`gpt-image-2.5-flare`が担う。[6] 音声およびリアルタイム発話ワークロードには、`gpt-live-1.1`（全二重多言語音声）、`gpt-live-1`、`gpt-live-transcribe`、`gpt-realtime-2.1`および`gpt-realtime-2.1-mini`（ツール利用を備えた推論音声モデル）、`gpt-realtime-translate`、`gpt-realtime-whisper`、`gpt-audio-1.5`、`gpt-transcribe`が提供されている。[6]

アプリケーション層では、OpenAIはコンシューマー向けプラン、ChatGPT Business、ChatGPT Enterprise、ChatGPT for Educationの各ChatGPTを展開するほか、ソフトウェアエンジニアリングエージェントプラットフォームのCodex、Dots、さらにAstra for Lawなどの業界特化イニシアチブや、Le Groupe FigaroおよびLVMHのメディア部門などの報道機関とのメディアパートナーシップを運営している。[2][3]

APIのレート制限（RPM、RPD、TPM、TPD、IPM、およびベクターストアあたり300 RPMの制限で計測）は、対応国・地域における累計クレジット購入額に応じて4つの名称付き利用ティアへ段階的に引き上げられる。[7]

- **Freeティア**: 許可対象地域のみ利用可能。利用上限は月額$100である。[7]
- **Buildティア**: 累計クレジット購入額$5で解放される。利用上限は月額$500である。[7]
- **Launchティア**: 累計クレジット購入額$100で解放される。利用上限は月額$5,000である。[7]
- **Growティア**: 累計クレジット購入額$500で解放される。利用上限は月額$200,000である。[7]

Webデータの収集とリアルタイム検索のため、OpenAIは独立した`robots.txt`制御と公開JSON IP許可リストを備えた4種類のHTTPユーザーエージェントを運用している。すなわち、生成AI基盤モデルの学習向けに公開Webコンテンツをクロールする`GPTBot/1.4`（`openai.com/gptbot.json`）、モデル学習を行わずにChatGPT検索結果向けにWebページをインデックスする`OAI-SearchBot/1.4`（`openai.com/searchbot.json`）、モデル学習を行わずにChatGPT上の広告として提出されたランディングページのポリシー準拠性と関連性を検証する`OAI-AdsBot/1.0`（`openai.com/adsbot.json`）、およびリアルタイムのユーザー質問やCustom GPTアクションによって起動される`ChatGPT-User/1.0`（`openai.com/chatgpt-user.json`）である。[7]

オープンソースエコシステムのガバナンスにおいて、OpenAIは2025年12月9日にAnthropicおよびBlockとともにLinux Foundation傘下のAgentic AI Foundation（AAIF）を共同設立し、リポジトリガイドライン仕様である`AGENTS.md`を創設プロジェクトとして寄贈するとともに、Amazon Web Services、Anthropic、Block、Bloomberg、Cloudflare、Google、Microsoftと並んでAAIFのプラチナ会員に加わった。[9]

## よくある質問

### 2025年10月の資本再編後、OpenAIの組織構造はどうなっていますか？

2025年10月28日以降、OpenAIは非営利法人のOpenAI Foundationと、その支配下にある営利公益法人のOpenAI Group PBCで構成されています。OpenAI FoundationはOpenAI Group PBCの全取締役を任命および交代させる独占的な特別議決権を保有し、ジコ・コルター博士が委員長を務める安全・セキュリティ委員会をFoundationレベルで維持するとともに、OpenAI Groupの普通株式26%（完了時評価額約1,300億ドル）および株価が10倍超に成長した場合に追加株式を取得できる15年満期ワラントを所有しています。 [2]

### MicrosoftはOpenAIの株式をどの程度保有していますか？

2025年10月の資本再編に伴うOpenAIの構造開示によると、MicrosoftはOpenAI Group PBCの株式の約27%を保有しています。OpenAI Foundationが26%（加えて長期の評価連動ワラント）を保有し、残りの47%を現職・元従業員およびその他の投資家が保有しています。すべての株主は、OpenAI Groupの企業価値に比例して参加する通常の普通株式を保有しています。 [2]

### 2026年後半時点のOpenAI APIラインナップにおける主要モデルは何ですか？

OpenAIの主力APIモデルは、複雑な推論およびコーディング向けのGPT-6.2 Astra（短文コンテキスト入力/出力100万トークンあたり$8/$40）、日常的なコーディングおよびスケーラブルなエージェント向けのGPT-6.2 Sol（$2/$10）、高速な視覚推論およびコンピュータ操作向けのGPT-6.1 Terra（$1/$5）、大量処理ワークロード向けのGPT-6 Luna（$0.10/$0.50）です。また、ドメイン特化モデル（GPT-6 Cyberおよびライフサイエンス向けのGPT-Rosalind）、マルチモーダルモデル（GPT-Image-2.6 Sunburst/Flare、GPT-Live-1.1、GPT-Realtime-2.1）、オープンウェイトモデル（gpt-oss-120bおよびgpt-oss-20b）も提供しています。 [6]

### OpenAIのWebクローラー（GPTBot、OAI-SearchBot、OAI-AdsBot、ChatGPT-User）の違いは何ですか？

OpenAIはサイト運営者が独立したrobots.txtルールを設定できるよう、機能ごとにWebクローラーを分離しています。GPTBot/1.4は生成AI基盤モデルの学習に使用される可能性のあるコンテンツをクロールします。OAI-SearchBot/1.4はChatGPTの検索結果に表示するためにWebサイトをインデックスします。OAI-AdsBot/1.0はモデル学習を行わずにChatGPT上の広告として提出されたランディングページのポリシー準拠性と関連性を検証します。ChatGPT-User/1.0はユーザーがChatGPTまたはCustom GPTにURLの閲覧を指示した際にオンデマンドでページを取得します。 [7]
