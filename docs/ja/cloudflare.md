# Cloudflare

> Cloudflare, Inc.はサンフランシスコに本社を置き、ニューヨーク証券取引所にティッカーシンボルNETで上場しているテクノロジー企業である。グローバルネットワークを通じてCDN、DNS、DDoS対策、Webアプリケーションファイアウォール、Zero Trust、ならびにWorkersやR2などのサーバーレス開発者サービスを提供している。Form 10-Kによると、2025会計年度の売上高は21億6,790万ドル、正社員数は5,156人である。

Cloudflare, Inc.は、2009年7月に米国デラウェア州で法人設立され、カリフォルニア州サンフランシスコに本社を置くテクノロジー企業である。グローバルネットワークを運営し、アプリケーションセキュリティおよびパフォーマンスサービス、SASEプラットフォーム、ならびにCloudflare WorkersやR2オブジェクトストレージを含む開発者プラットフォームを提供している。クラスA普通株式は2019年9月13日よりニューヨーク証券取引所にティッカーシンボルNETで上場している。2025年12月31日に終了した会計年度において、Cloudflareは売上高21億6,790万ドルおよび正社員数5,156人を報告した。Cloudflareは価格を公開しているFree、Pro、Businessプランに加え、個別見積もりのContractプランを提供している。

## Cloudflareのアプリケーションサービス料金プラン

Cloudflareは料金ページの「Network & CDN」タブにて、Free、Pro、Business、Contractの4つのアプリケーションサービスプランを公開している。[5] 2026-11-21時点で同ページに掲載されている米ドル建ての料金は以下の通りである。[5]

| プラン | 表示価格 | 請求条件 | Cloudflareが示す想定用途 |
| --- | --- | --- | --- |
| Free | 月額0ドル | 無料 | 個人または趣味のプロジェクト |
| Pro | 月額20ドル | 年払い（月払いの場合は月額25ドル） | プロフェッショナルなWebサイト |
| Business | 月額200ドル | 年払い（月払いの場合は月額250ドル） | オンラインで事業を展開する中小企業 |
| Contract | 個別見積もり | 年払い | ミッションクリティカルなアプリケーション |

CloudflareのProおよびBusinessプランの価格は請求サイクルによって異なり、月払いの表示価格は年払いよりもProで月額5ドル、Businessで月額50ドル高く設定されている。[5] Contractプランには公開価格がなく、料金ページのリンクはCloudflareのエンタープライズパッケージのページへ遷移する。[5] 同ページのプラン比較表では、DNS、無制限（unmetered）DDoS対策、[コンテンツデリバリーネットワーク](https://mimirwiki.com/ja/wiki/content-delivery-network)（CDN）、Universal SSL証明書、およびWebアプリケーションファイアウォール（WAF）が全4プランに含まれると明記されており、100%稼働時間サービスレベル契約（SLA）はBusinessおよびContractプランのみに記載されている。[5]

また、Cloudflareの料金ページでは2026-11-21時点で3つのSASEおよびZero Trustプランも掲載されている。50ユーザーまで無料のFree（0ドル）、ユーザーあたり月額7ドルのPay-as-you-go、およびユーザーあたりの年額を個別見積もりとするContractである。[5]

## Cloudflare Workersのプラン、制限および料金

[Cloudflare Workers](https://mimirwiki.com/ja/wiki/cloudflare-workers)はCloudflareの開発者プラットフォームにおけるサーバーレスコンピューティング製品であり、Workers Freeプランと、アカウントあたり月額最低5ドルのWorkers Paidプランで提供されている。[6] Workers Paidの利用料金はStandard使用量モデルに従い、リクエスト数とCPU時間に基づいて課金され、実行時間（duration）に対する課金やデータ転送（エグレス）および帯域幅に対する追加課金はない。[6] 以下の数値は2026-11-21にCloudflareの公式ドキュメントから確認したものであり、料金の行はWorkers料金ページ、制限の行はWorkers制限ページに基づいている。[6][7]

| 項目 | Workers Free | Workers Paid |
| --- | --- | --- |
| リクエスト数 | 1日あたり100,000件 | 月間1,000万件まで含む、超過分は100万件あたり0.30ドル |
| CPU時間 | 1回の呼び出しあたり10 ms | 月間3,000万CPU msまで含む、超過分は100万CPU msあたり0.02ドル |
| HTTPリクエストあたりの最大CPU時間 | 10 ms | 5分（デフォルト30秒） |
| アイソレートあたりのメモリ | 128 MB | 128 MB |
| 1リクエストあたりのサブリクエスト数 | 50件 | 10,000件 |
| Workerサイズ | 64 MiB | 64 MiB |
| アカウントあたりのWorker数 | 100個 | 500個 |
| アカウントあたりのCron Triggers数 | 5個 | 1,000個 |

Cloudflare Workers Freeの1日あたりのリクエスト上限はUTC午前0時にリセットされ、Workerが上限を超過するとCloudflareはError 1027を返す。[7] Workerが発行するサブリクエストに対してCloudflareは課金しない。[6]

Cloudflareの開発者ドキュメントは自動化された読者向けの形式でも公開されている。2026-11-21時点で、Workersのドキュメントページには[llms.txt](https://mimirwiki.com/ja/wiki/llms-txt)インデックス、`llms-full.txt`ファイル、各ページのMarkdown版へのリンクが用意されており、ドキュメントのナビゲーションからはGitHub上のCloudflare製[Model Context Protocol](https://mimirwiki.com/ja/wiki/model-context-protocol)サーバーへリンクされている。[6]

## Cloudflare R2、D1、Workers KV、Queues、Durable Objectsの料金

[Cloudflare R2](https://mimirwiki.com/ja/wiki/cloudflare-r2)はCloudflareのオブジェクトストレージサービスであり、その料金ページではすべてのストレージクラスにおいてエグレス帯域幅の課金がないと明記されている。[8] R2は保存データ量と2種類のオペレーションに対して課金され、データ取得料金はInfrequent Accessストレージクラスのみに適用される。[8] 以下の料金は2026-11-21に確認したものである。[8]

| R2項目 | Standardストレージ | Infrequent Accessストレージ |
| --- | --- | --- |
| ストレージ | 0.015ドル / GB-月 | 0.01ドル / GB-月 |
| Class Aオペレーション | 4.50ドル / 100万リクエスト | 9.00ドル / 100万リクエスト |
| Class Bオペレーション | 0.36ドル / 100万リクエスト | 0.90ドル / 100万リクエスト |
| データ取得 | なし | 0.01ドル / GB |
| インターネットへのエグレス | 無料 | 無料 |

Cloudflare R2の無料枠には、月間10 GB-月のストレージ、100万件のClass Aリクエスト、1,000万件のClass Bリクエストが含まれ、Standardストレージのみに適用される。[8] Cloudflareは、R2バケットに接続された他の従量課金サービスについては別途料金が発生する場合があるとしている。[8]

Cloudflareは開発者プラットフォームの他のデータ製品の料金をWorkers料金ページに掲載している。[6] 2026-11-21時点で記載されていた無料枠および料金単価は以下の通りである。[6]

| D1 書き込み行数 | 1日あたり100,000行 | 月間5,000万行まで含む、超過分は100万行あたり1.00ドル |

## CloudflareのAIクローラー制御とWeb Bot Auth

Cloudflareは、自社ネットワーク経由で配信されるコンテンツへのAIクローラーのアクセス方法をサイト所有者が決定できるようにする一連の制御機能を発表してきた。[11][14] 2025年7月1日、Cloudflareはすべての新規ドメインに対して登録時にAIクローラーを許可するかどうかを確認する仕組みを発表し、許可や対価なしにコンテンツへアクセスするAIクローラーをデフォルトでブロックする変更であると説明した。[11]

同日、Cloudflareはpay per crawlをプライベートベータとして発表した。[12] pay per crawlでは、サイト所有者がドメイン全体に対してリクエストあたりの一律料金を設定し、クローラーはリクエストヘッダーで支払い意思を示すか、HTTP 402 Payment Requiredレスポンスを受け取る仕組みとなっており、Cloudflareが販売事業者（merchant of record）を務める。[12]

[Web Bot Auth](https://mimirwiki.com/ja/wiki/web-bot-auth)は、Cloudflareがクローラーおよびエージェントの身元を検証するために使用する、HTTP Message Signaturesに基づくボット認証方式である。[13] Cloudflareは2025年5月にHTTP Message Signaturesによるボットおよびエージェントの識別提案とWeb Bot AuthのIETFドラフトを公開し、2025年7月1日にHTTP Message SignaturesをVerified Bots Programへ統合することを発表した。[13] pay per crawlに参加するクローラーはEd25519鍵ペアを生成し、公開鍵をホストされたディレクトリに公開したうえで、各リクエストにHTTP Message Signaturesで署名する。[12]

2026年7月1日、CloudflareはFreeプランを含むすべての顧客向けに、AIトラフィックをSearch、Agent、Trainingの3つの挙動別に管理する制御機能を導入した。[14] 同じ発表の中でCloudflareは、2026年9月15日より新規ドメインでは広告を表示するページにおいてTrainingおよびAgentトラフィックをデフォルトでブロックし、Searchは引き続き許可すると述べた。[14]

2026年9月15日、CloudflareはDisallow AI Training設定を発表した。この設定はrobots.txtに学習禁止の意思表示を公開し、CloudflareがAccountableに指定する複合用途（mixed-use）クローラーは検索目的でのアクセスを引き続き許可する一方、その他の学習用クローラーをブロックするものである。[15] 同発表では、この設定を遵守している、または遵守を表明した事業者としてApple、Google、Microsoftを挙げ、従来のBlock AI BotsオプションはSearch、Training、Agent制御へ移行するため非推奨になると述べている。[15]

## よくある質問

### Cloudflare Proの料金はいくらですか？

2026-11-21時点で、Cloudflareの料金ページではProプランが年払いの場合月額20ドル、月払いの場合月額25ドルと記載されています。Businessプランは年払いの場合月額200ドル、月払いの場合月額250ドルです。Freeプランは0ドルであり、Contractとして記載されている最上位プランは年払いの個別見積もりとなっています。 [5]

### Cloudflare R2はエグレス料金がかかりますか？

いいえ、かかりません。2026-11-21時点で、Cloudflare R2の料金ページではすべてのストレージクラスでエグレス帯域幅に対する料金は発生しないと明記されています。R2ではストレージ容量（StandardストレージでGB-月あたり0.015ドル）およびClass A・Class Bオペレーションに対して課金され、バケットに接続された他の従量課金サービスについては別途料金が発生する場合があります。 [8]

### Cloudflare Workers無料プランの制限はどのようになっていますか？

2026-11-21時点で、Workers Freeプランでは1日あたり100,000リクエスト、1回の呼び出しあたりCPU時間10ミリ秒、メモリ128 MB、1リクエストあたり50件のサブリクエストが許可されています。Workers Paidプランは月額最低5ドルから利用でき、月間1,000万リクエストおよび3,000万CPUミリ秒が含まれています。 [6][7]

### CloudflareはAIクローラーをデフォルトでブロックしますか？

2025年7月1日、Cloudflareはすべての新規ドメインに対して登録時にAIクローラーを許可するか確認すると発表しました。2026年7月1日には全プラン向けにSearch、Agent、Trainingの個別制御を追加し、2026年9月15日より新規ドメインでは広告を表示するページにおいてTrainingおよびAgentトラフィックをデフォルトでブロックし、Searchは許可すると発表しました。サイト所有者はこれらの設定を変更できます。 [11][14]

### CloudflareはSOC 2およびISO 27001認証を取得していますか？

2026-11-21時点で、CloudflareのコンプライアンスリソースページにはSOC 2 Type II、ISO 27001:2022、ISO 27701:2019、PCI DSS 4.0、FedRAMP Highなどの認証および検証が掲載されています。Cloudflareは、関連するコンプライアンス文書をダッシュボードから入手できるとしています。 [9]

### Cloudflareのティッカーシンボルと上場市場はどこですか？

- 2026-11-21時点で、Cloudflare Workers Freeプランは1日あたり100,000リクエストおよび1回の呼び出しあたり10ミリ秒のCPU時間を許可している。 [6]
- 2026-11-21時点で、Cloudflare R2はいずれのストレージクラスにおいてもエグレス帯域幅料金を課していない。 [8]
- 2025年7月1日、Cloudflareはすべての新規ドメインに対して登録時にAIクローラーを許可するか確認すると発表した。 [11]

- 2025-07-01: Cloudflareが新規ドメインの登録時にAIクローラーの許可を確認する方針と、pay per crawlのプライベートベータを発表した。 [11][12]
- 2026-02-26: Cloudflareが2025会計年度のForm 10-Kを提出し、売上高21億6,790万ドルを報告した。 [1][2]
- 2026-04-01: Alissa StarzakがDouglas Kramerの後任としてCloudflareの最高法務責任者兼秘書役に就任した。 [3]
- 2026-05-07: Cloudflareが従業員の約20%を削減する見込みのリストラクチャリング計画を開示した。 [4]
- 2026-07-01: Cloudflareが全顧客向けにAIトラフィックのSearch、Agent、Training制御を導入した。 [14]
- 2026-09-15: Cloudflareが複合用途クローラー向けのDisallow AI Training設定を発表した。 [15]
