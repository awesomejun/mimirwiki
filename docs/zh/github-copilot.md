# GitHub Copilot

> GitHub Copilot 是由 GitHub 开发的 AI 编程助手与智能体平台，其云服务归入 Microsoft Corporation 的 Intelligent Cloud 业务部门。该产品于 2021 年 6 月 29 日发布技术预览版，于 2022 年 6 月 21 日全面推出，可在 IDE、终端、桌面应用和 github.com 上运行。截至 2026-11-23，GitHub Copilot 提供多厂商模型支持和 AI Credits 计费模式。

GitHub Copilot 是由 GitHub 开发的人工智能编程助手与智能体平台，其云端和本地产品在 Microsoft Corporation 的 Intelligent Cloud 业务部门下报告。GitHub 于 2021 年 6 月 29 日基于 OpenAI Codex 推出 GitHub Copilot 有限技术预览版，于 2022 年 6 月 21 日面向个人开发者全面推出，并于 2024 年 12 月 18 日上线 GitHub Copilot Free 免费层。截至 2026-11-23，GitHub Copilot 可在代码编辑器、命令行、桌面应用程序、github.com、GitHub Mobile、Slack 和 Microsoft Teams 中运行，支持 OpenAI、Anthropic、Google、Microsoft、xAI 和 Kimi 的 AI 模型，同时支持用户自带 API 密钥和本地模型运行时。截至 2026-11-23，GitHub 提供个人方案（Free、Student、每月 10 美元的 Pro、每月 39 美元的 Pro+ 以及每月 100 美元的 Max）和组织或企业方案（每席位每月 19 美元的 Business、每席位每月 39 美元的 Enterprise 以及 Copilot access），按量计费功能通过 GitHub AI Credits 结算，每额度 0.01 美元。

## GitHub Copilot 发布历程与 Microsoft 财报披露背景

GitHub Copilot 于 2021 年 6 月 29 日由 GitHub 以有限技术预览版形式推出，由 GitHub 与 [OpenAI](https://mimirwiki.com/zh/wiki/openai) 合作开发并由 [OpenAI Codex](https://mimirwiki.com/zh/wiki/openai-codex) 驱动。[7] 发布之初，GitHub 将 Copilot 定位为 AI 结对程序员（AI pair programmer），能够从当前打开的代码中提取上下文以补全整行代码或整个函数；该工具基于包含高比例公开源代码的数据集进行训练，支持多种编程语言，尤其在 Python、JavaScript、TypeScript、Ruby 和 Go 上表现突出。[7]

2022 年 6 月 21 日，GitHub 以编辑器扩展的形式向所有个人开发者全面开放 GitHub Copilot，定价为每月 10 美元或每年 100 美元，同时提供免费试用，并向经认证的学生和热门开源项目维护者免费提供。[8] 2024 年 12 月 18 日，在 GitHub 平台开发者数量达到 1.5 亿之际，时任 GitHub 首席执行官（任期 2021 年至 2025 年）Thomas Dohmke 宣布推出集成于 Visual Studio Code 且可从 GitHub 仪表板访问的 GitHub Copilot Free。[9] 推出时，Copilot Free 每月提供 2,000 次代码补全和 50 条聊天消息，支持 [Anthropic](https://mimirwiki.com/zh/wiki/anthropic) 的 [Claude](https://mimirwiki.com/zh/wiki/claude) 3.5 Sonnet 和 OpenAI 的 GPT-4o，启用多文件编辑与第三方智能体功能，同时保持学生、教育工作者及开源项目维护者免费无限使用 Copilot Pro 的权益不变。[9]

在 Microsoft Corporation 截至 2026 年 6 月 30 日财年的 Form 10-K 报告（[SEC EDGAR](https://mimirwiki.com/zh/wiki/sec-edgar) 上的 SEC 中央索引号 0000789019）中，GitHub 被描述为提供云端及本地部署产品的平台，供开发者管理代码并在整个软件开发生命周期中集成 AI 与基于智能体的工具。[1] Microsoft 将 GitHub 云服务归入 Intelligent Cloud 业务部门下的服务器产品与云服务类别，并将 GitHub 云服务收入计入 Azure 及其他云服务收入增长指标，但未在相关摘录中单独披露 GitHub Copilot 的独立收入。[1] 截至 2026 年 6 月 30 日财年，Microsoft 在其 Form 10-K 中报告的合并财务业绩如下。[1]

## GitHub Copilot AI Credits 与计费模式

截至 2026-11-23，GitHub Copilot 使用 GitHub AI Credits 对各方案中的交互式与智能体 AI 使用量进行计量，1 个 AI 额度等值于 0.01 美元。[6] 聊天、智能体模式、代码审查、Copilot in the cloud、Copilot CLI 以及 Copilot 应用均会消耗 AI 额度，每次交互的额度消耗取决于所选模型和任务复杂度。[5][6] 内联代码补全和下一编辑建议不消耗 AI 额度，在付费方案中保持无限制，即便组织用户的预算设为 0 美元或已触及强制支出上限也是如此。[3][6]

截至 2026-11-23，个人付费方案的每月总额度由与月费等值的固定基础额度（Pro 为 10 美元、Pro+ 为 39 美元、Max 为 100 美元）和 GitHub 注明可能随时间调整的可变弹性额度（Pro 为 5 美元、Pro+ 为 31 美元、Max 为 100 美元）共同组成。[5] 用户用尽月度额度后，可以等待下月重置、切换至单次交互额度消耗更低的轻量级模型，或按每额度 0.01 美元（10 美元可覆盖 1,000 额度）设定美元预算以进行额外按需付费；Free 方案不支持购买额外额度。[5][6] Copilot 设置中的预算跟踪功能会在已设预算达到 75%、90% 和 100% 时发出使用提醒。[6]

面向组织和企业，Copilot Business 与 Copilot Enterprise 许可证会将其月度额度汇入组织级共享池，若管理员允许付费超额使用，超出共享池的部分将另行计费。[3][5][6] 若管理员禁止额外付费使用，Copilot 将暂停服务直至下一个计费周期。[6] 在 Copilot access 方案下，无内置额度，按量使用自首次调用起即开始计费。[3] 每个 Copilot 席位代表一名用户的许可证，即便该席位不产生额外费用（0 美元增量费用）也必须完成分配；在 Copilot access 和 Copilot Business 中，企业所有者可直接向个人或企业团队分配席位，从而使团队中的每位成员获得席位。[3] 满足数据驻留（data-resident）和 FedRAMP 合规要求的 Copilot 请求会适用 10% 的模型乘数上浮。[3]

## GitHub Copilot 支持终端、IDE 集成与智能体功能

截至 2026-11-23，GitHub Copilot 可在编辑器、终端、桌面软件、Web 界面和即时通讯应用程序中运行，并支持在一个端发起的会话无缝延续到另一端。[5][6] GitHub 列出的受支持编辑器与 IDE 环境包括 Visual Studio Code、Visual Studio、JetBrains IDE、Xcode、Vim、Neovim、Zed、Eclipse、Raycast 和 SQL Server Management Studio。[5][6] 除编辑器外，GitHub Copilot 还可通过 Copilot CLI 在终端中运行，并在 GitHub Copilot 桌面应用（包含 macOS Apple Silicon 构建版本）、github.com、GitHub Mobile、Slack 及 Microsoft Teams 中使用。[5][6]

截至 2026-11-23，GitHub 列出的核心编程与智能体功能包括以下各项。[5][6]

- **内联建议与下一编辑建议**：面向公开代码库中出现的各类编程语言提供实时代码补全，Free 方案每月上限为 2,000 次补全，付费方案无限制。[5][6]
- **IDE 智能体模式**：在 Free、Pro、Pro+ 和 Max 方案中提供，覆盖 Visual Studio Code、Visual Studio、JetBrains IDE、Eclipse 和 Xcode。[5]
- **Copilot in the cloud**：在付费方案中提供，无论是否创建拉取请求均可开展研究、规划与代码编写，支持从议题（issue）、拉取请求、编辑器、智能体面板或第三方项目管理工具发起并跟踪任务，并运行并行会话。[5][6]
- **Copilot CLI**：包含于所有方案中，可在终端内工作、向编程智能体委派任务、在本地或 GitHub 上修改并提交代码，并支持编程模式（programmatic mode）运行。[2][5]
- **代码审查与现代化改造**：在 Pro 及以上方案中提供，支持 GitHub 拉取请求审查、代码编辑器内本地文件差异（diff）审查、通过 `instructions.md` 配置自定义审查指令，以及面向 Java 和 .NET 的应用现代化改造。[5][6]
- **自动化与第三方智能体**：可复用的智能体任务支持按需运行、定时运行或通过受支持触发器运行，且受支持方案可将任务委派给包括 Claude by Anthropic 和 [OpenAI Codex](https://mimirwiki.com/zh/wiki/openai-codex) 在内的第三方编程智能体。[5][6]

在自定义与外部工具接入方面，GitHub Copilot 支持自定义指令（custom instructions）、自定义智能体、智能体技能（agent skills）、Copilot Spaces、Copilot Connectors、插件，并在 IDE 智能体模式和 Copilot in the cloud 中均支持 [Model Context Protocol](https://mimirwiki.com/zh/wiki/model-context-protocol)（MCP）服务器。[5][6]

## GitHub Copilot 内容过滤、隐私与企业治理

截至 2026-11-23，GitHub Copilot 对所有默认 AI 模型均实施内容过滤，将输入提示词和输出补全内容均送入过滤器，以筛除有害、冒犯性或偏离主题的内容。[4] 启用后，GitHub Copilot 还会运行带代码引用（code referencing）功能的公开代码匹配过滤器，该功能在 Free、Pro、Pro+ 和 Max 方案中均列为包含项。[4][5]

截至 2026-11-23，GitHub 在其产品隐私常见问题中表示，GitHub Copilot 会根据所用客户端终端和功能处理以下四类个人数据。[6]

- **用户参与数据（User Engagement Data）**：交互过程中记录的假名化标识符，包括采纳或忽略的补全记录、错误消息、系统日志及产品使用指标。[6]
- **提示词（Prompts）**：为生成建议而发送的聊天或代码输入及其周边上下文。[6]
- **建议（Suggestions）**：根据提示词返回的 AI 生成代码行或聊天回复。[6]
- **反馈数据（Feedback Data）**：实时用户反馈，例如点赞或点踩操作、可选评论以及支持反馈。[6]

面向组织与企业，Copilot Business 和 Copilot Enterprise 增加了集中式席位管理、Copilot 策略控制、共享额度池，以及用于决定是否允许超额使用的管理员支出上限。[2][3][6] 企业方案还涵盖个人方案中不包含的功能，包括 SAML SSO 身份验证、github.com 用户管理、组织使用指标、企业级安全与知识产权赔偿，而审计日志自 Pro+ 起列入提供范围。[5] 需要数据驻留或 FedRAMP 合规请求处理的组织将对相关请求承担 10% 的模型乘数上浮。[3]

## 常见问题

### GitHub Copilot 有哪些订阅方案和价格？

截至 2026-11-23，GitHub 提供五种个人方案：Free（0 美元）、Student（经认证学生 0 美元）、Pro（每月 10 美元）、Pro+（每月 39 美元）和 Max（每月 100 美元）。面向组织和企业，GitHub 列出 Copilot Business（每席位每月 19 美元）、Copilot Enterprise（每席位每月 39 美元）以及 Copilot access（已获许可的 GitHub Enterprise Cloud 用户为 0 美元，Copilot Standalone 为每用户每月 10 美元，按量计费部分另行收取）。 [2][3][5]

### GitHub AI Credits 在 GitHub Copilot 中如何运作？

截至 2026-11-23，1 个 GitHub AI Credit 等值于 0.01 美元，用于根据所选模型和任务复杂度支付聊天、智能体模式、代码审查、Copilot in the cloud、Copilot CLI 和 Copilot 应用的使用费用。内联代码补全和下一编辑建议不消耗额度，并在付费方案中保持无限制。Business 和 Enterprise 席位会将额度汇入组织共享池，可选的按需付费支出预算会在达到 75%、90% 和 100% 时触发提醒。 [3][5][6]

### GitHub Copilot 支持哪些 AI 模型？

截至 2026-11-23，GitHub Copilot 支持来自 OpenAI（GPT-5 和 GPT-6 系列）、Anthropic（Claude Fable、Haiku、Sonnet 和 Opus 系列）、Google（Gemini 3.7、3.8 和 Gemini 4 系列）、Microsoft（MAI Code 系列）、xAI（Grok 4.5 至 4.7）以及 Kimi（Kimi K3）的模型。用户既可以让 Copilot Fusion 自动路由任务，也可以手动选择特定模型，或使用自有 API 密钥连接云服务商，还可通过 Ollama 和 Foundry Local 运行本地模型。 [4][5][6]

### GitHub Copilot Free 包含哪些功能？

截至 2026-11-23，GitHub Copilot Free 价格为 0 美元且无需绑定信用卡，包含每月 2,000 次内联代码补全、有限额的聊天和智能体使用、Copilot CLI、Copilot 应用、Copilot Spaces、智能体模式下的 Model Context Protocol 服务器集成、Copilot Fusion Standard 以及社区支持。该方案不包含代码审查、Copilot in the cloud、由指定智能体创建拉取请求（pull request）以及额外额度购买。 [2][5][6][9]

### GitHub Copilot 支持哪些 IDE 和平台？

截至 2026-11-23，GitHub Copilot 可在 Visual Studio Code、Visual Studio、JetBrains IDE、Xcode、Vim、Neovim、Zed、Eclipse、Raycast 和 SQL Server Management Studio 中使用。它还通过 Copilot CLI 运行于终端，并在 GitHub Copilot 桌面应用、github.com、GitHub Mobile、Slack 和 Microsoft Teams 中提供服务，但不支持 GitHub Enterprise Server。 [2][5][6]

### Microsoft 如何在 SEC Form 10-K 中披露 GitHub Copilot？

在 Microsoft Corporation 截至 2026 年 6 月 30 日财年的 Form 10-K 报告中，GitHub 云服务归入 Intelligent Cloud 业务部门下的服务器产品与云服务类别，并计入 Azure 及其他云服务收入增长指标。该 Form 10-K 将 GitHub 描述为提供云端及本地部署协作工具的平台，在整个软件开发生命周期中融合 AI 和基于智能体的能力，但未在这些披露中单独列示 GitHub Copilot 的独立收入。 [1]
