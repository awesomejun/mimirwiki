# OpenAI

> OpenAI 于 2015 年作为非营利组织成立，并于 2025 年 10 月 28 日重组为由非营利组织 OpenAI 基金会控股营利性 OpenAI Group PBC 的架构，负责开发包括 GPT-6.2 Astra 和 Sol、ChatGPT 及 Codex 在内的前沿 AI 模型。截至资本重组完成时，OpenAI 基金会持有 26% 股权（估值约 1,300 亿美元，外加一份 15 年期业绩认股权证），微软持有约 27%，员工与投资者持有 47%；基金会负责任命 Group 的全部董事，并承诺初期投入 250 亿美元用于医疗健康突破与 AI 韧性建设。

OpenAI 是一家总部位于美国旧金山的人工智能研究与部署机构，成立于 2015 年，其既定使命是确保通用人工智能（AGI）造福全人类。继 2025 年 10 月 28 日宣布结构性资本重组后，OpenAI 通过非营利组织 OpenAI 基金会（OpenAI Foundation）及其控股的营利性子公司 OpenAI Group PBC（一家公益公司）开展运营，开发 ChatGPT 平台、Codex，以及 GPT-6、GPT-5、GPT-Image、GPT-Live 和开放权重 gpt-oss 系列模型。

## OpenAI 的历史、AGI 使命与 OpenAI 宪章

OpenAI 成立于 2015 年，最初是一家非营利研究机构，致力于确保通用人工智能（AGI，在《OpenAI 宪章》中被定义为在大多数具有经济价值的工作中超越人类的高度自主系统）造福全人类。[2][4] 其 GitHub 组织账号（`github.com/openai`）创建于 2015 年 10 月 3 日，截至 2026 年底托管了 280 个公开代码仓库。[8] 2019 年，OpenAI 成立了一家由原非营利董事会控制的营利性子公司，以筹集资金并扩大算力密集型模型的训练与部署规模。[2]

《OpenAI 宪章》（OpenAI Charter）规定了指导该机构运作的四项基本原则：[4]

1. **广泛分配的利益（Broadly Distributed Benefits）**：OpenAI 承诺将其在 AGI 部署中获得的任何影响力用于广泛造福人类，避免对人类造成伤害或导致权力过度集中的用途，并将对人类的受托责任置于首位，同时尽量减少利益相关者之间的利益冲突。[4] 2. **长期安全性（Long-Term Safety）**：OpenAI 承诺开展并分享安全对齐研究，并包含一项后期“停止竞争、转为协助”条款：如果某个价值观一致且注重安全的外部项目在 OpenAI 之前接近建成 AGI（通常定义为未来两年内成功概率超过 50%），OpenAI 承诺停止竞争并转而协助该项目。[4] 3. **技术领先地位（Technical Leadership）**：鉴于仅靠政策与安全倡导而不处于 AI 能力前沿是不够的，OpenAI 致力于在与自身使命直接一致的前 AGI 能力领域保持领先。[4] 4. **合作导向（Cooperative Orientation）**：OpenAI 承诺与外部研究及政策机构合作并提供公共产品，同时指出出于安全与安保考量，其成果输出将逐步从传统的开放能力发布转向分享安全、政策与标准研究。[4]

## OpenAI 2025 年 PBC 资本重组、董事会治理与股权结构

2025 年 10 月 28 日，经过与加利福尼亚州和特拉华州总检察长办公室近一年的正式磋商，OpenAI 完成了一项全面资本重组，在保持非营利组织对商业实体控制权的同时简化了公司架构：[2][3]

- **OpenAI 基金会（控股非营利组织）**：原 501(c)(3) 非营利母体更名为 OpenAI 基金会（OpenAI Foundation）。[2][3] OpenAI 基金会拥有排他性的特别投票权与治理权，负责任命营利性公司董事会的全部成员，并保留随时撤换任何董事的单方面权力。[2]
- **OpenAI Group PBC（受控公益公司）**：原营利性子公司改制为名为 OpenAI Group PBC 的特拉华州公益公司（Public Benefit Corporation），从法律上约束该商业实体推进与 OpenAI 基金会完全一致的使命，并在实现商业增长的同时权衡所有利益相关者的广泛利益。[2][3]

根据董事会一致批准的资本重组条款，此前所有复杂的利润上限权益单位均转换为 OpenAI Group PBC 的常规普通股，按比例分享企业价值增长：[2]

| 股权持有者类别 | 资本重组完成时持股比例 | 估值 / 条款与权利 |
| --- | --- | --- |
| OpenAI 基金会（非营利组织） | 26% + 业绩认股权证 | 完成时估值约 1,300 亿美元（隐含整体估值约 5,000 亿美元），外加一份 15 年期认股权证，若股价涨幅超过 10 倍则授予大量额外股权 |
| 微软公司（Microsoft Corporation） | 约 27% | 根据微软 2026 财年 Form 10-K 披露的多年期云服务与知识产权协议确立的长期战略合作伙伴 |
| 现任/前任员工及投资者 | 约 47% | 常规按比例分配的普通股 |

凭借约 1,300 亿美元的初始股权价值，OpenAI 基金会启动了一项初期 250 亿美元的公益承诺，聚焦两大支柱：加速医疗健康突破与疾病治疗（包括开源前沿医疗数据集及科研资助），以及构建 AI 韧性技术解决方案（保护电网、医院、金融系统和关键基础设施免受 AI 相关风险侵害），在其 5,000 万美元的 People-First AI Fund 基础上进一步扩展。[3]

OpenAI 基金会由一个 11 人董事会治理，成员包括主席布雷特·泰勒、CEO 萨姆·奥尔特曼、亚当·德安杰洛、保罗·克里斯蒂亚诺、苏·德斯蒙德-赫尔曼博士、齐科·科尔特博士、美国陆军退役上将保罗·M·中曾根、阿德巴约·奥贡莱西、妮可·塞利格曼、大卫·贝莱斯以及罗宾·文斯。[2] 为防止治理碎片化同时保持独立的安全监督，安全与保障委员会（Safety and Security Committee，简称 SSC）继续作为 OpenAI 基金会的常设委员会，全面监督基金会与 OpenAI Group PBC 的所有安全实践。[2] SSC 主席齐科·科尔特博士仅在 OpenAI 基金会董事会担任有表决权的董事，在 OpenAI Group PBC 董事会仅作为无表决权观察员列席（另有一名基金会董事计划在资本重组后一年内转为专任基金会表决董事及 Group 无表决权观察员）。[2]

## OpenAI 的模型阵容与产品生态（GPT-6.2 时代）

截至 2026 年 11 月，OpenAI 的 API 与产品目录以采用天体命名梯队的 GPT-6 和 GPT-6.2 模型系列（`Astra`、`Sol`、`Terra` 和 `Luna`）为核心，主要通过 Responses API 和官方客户端 SDK 交付，同时辅以专用多模态、音频、生命科学及开放权重版本：[5][6]

- **GPT-6.2 与 GPT-6 推理及智能体系列**：由 `gpt-6.2-astra`（发布于 2026 年 11 月 17 日，面向复杂端到端项目与前沿编程）和 `gpt-6.2-sol`（面向日常编程与智能体规模化扩展）领衔，此外还包括 `gpt-6.1-sol`、`gpt-6.1-terra`（快速视觉推理、计算机操控与自然写作）、`gpt-6-astra`、`gpt-6-sol` 以及 `gpt-6-luna`（超低成本、高吞吐任务）。[5][6] 当前所有旗舰文本模型均支持文本与图像输入、文本输出，并支持可配置的上下文缓存，提供 30 分钟和 12 小时两种缓存写入保留选项。[5][6]
- **领域专用前沿模型**：OpenAI 维护面向受限访问场景的领域模型，包括 `gpt-6-cyber` 和 `gpt-5.6-cyber`（用于经授权的漏洞研究、复现与补丁验证），以及 `gpt-rosalind-research`（GPT-Rosalind，为获批机构提供生命科学与药物化学推理）。[6]
- **前代与开放权重模型**：目录保留了 `gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`、`gpt-5.5` 与 `gpt-5.5-pro`、`gpt-5.4`（`pro`、`mini`、`nano`）、`gpt-5.2`（`pro`）、`gpt-5.1`、`gpt-5`、`gpt-4.1`、`gpt-4o` 以及 `o3`/`o3-pro`，并提供两款开放权重模型：`gpt-oss-120b`（专为单张 NVIDIA H100 GPU 部署而设计）和 `gpt-oss-20b`（中型低延迟开放权重模型）。[5][6]
- **图像、语音与实时多模态模型**：视觉生成由 `gpt-image-2.6-sunburst`、`gpt-image-2.6-flare`、`gpt-image-2.5-sunburst` 和 `gpt-image-2.5-flare` 提供支持。[6] 音频与实时语音工作负载由 `gpt-live-1.1`（全双工多语言语音）、`gpt-live-1`、`gpt-live-transcribe`、`gpt-realtime-2.1` 与 `gpt-realtime-2.1-mini`（支持工具调用的推理语音模型）、`gpt-realtime-translate`、`gpt-realtime-whisper`、`gpt-audio-1.5` 及 `gpt-transcribe` 提供支持。[6]

在应用层，OpenAI 运营涵盖个人版、ChatGPT Business、ChatGPT Enterprise 和 ChatGPT for Education 的 ChatGPT 产品线，以及软件工程智能体平台 Codex、Dots，并开展 Astra for Law 等垂直领域项目，同时与费加罗集团（Le Groupe Figaro）及 LVMH 媒体部门等出版机构建立了媒体合作关系。[2][3]

## OpenAI 的 API 定价架构、使用层级与网络爬虫

OpenAI 将 API 定价划分为四种执行速度模式：Standard（标准）、Batch（批处理，提供 2 小时或 8 小时异步完成窗口并享 50% 折扣）、Fast（快速，标准价格的 2 倍）以及 Ultrafast（超快，适用于符合条件的 GPT-6 模型，为标准价格的 6 倍）。[5][7] 传统的 Flex 测试版处理仅在较旧模型（最高至 GPT-6.1 Sol/Terra 和 GPT-6 Astra）上保持可用，不适用于 GPT-6.2。[5]

| 模型 ID | Standard 短上下文输入 / 输出（每百万 Token） | Standard 缓存输入 | Standard 长上下文输入 / 输出 | Batch 短上下文输入 / 输出 | Fast 短上下文输入 / 输出 |
| --- | --- | --- | --- | --- | --- |
| `gpt-6.2-astra` | $8.00 / $40.00 | $0.40（30 分钟 $10 / 12 小时 $20 写入） | $16.00 / $60.00 | $4.00 / $20.00 | $16.00 / $80.00 |
| `gpt-6.2-sol` | $2.00 / $10.00 | $0.10（30 分钟 $2.50 / 12 小时 $5 写入） | $4.00 / $15.00 | $1.00 / $5.00 | $4.00 / $20.00 |
| `gpt-6-astra` | $10.00 / $50.00 | $1.00（30 分钟 $12.50 / 12 小时 $25 写入） | $20.00 / $75.00 | $5.00 / $25.00 | $20.00 / $100.00 |
| `gpt-6.1-sol` | $2.00 / $10.00 | $0.10（30 分钟 $2.50 / 12 小时 $5 写入） | $4.00 / $15.00 | $1.00 / $5.00 | $4.00 / $20.00 |
| `gpt-6.1-terra` | $1.00 / $5.00 | $0.05（30 分钟 $1.25 / 12 小时 $2.50 写入） | $2.00 / $7.50 | $0.50 / $2.50 | $2.00 / $10.00 |
| `gpt-6-luna` | $0.10 / $0.50 | $0.01（30 分钟 $0.125 / 12 小时 $0.25 写入） | $0.20 / $0.75 | $0.05 / $0.25 | $0.20 / $1.00 |
| `gpt-5.5` (<272K) | $5.00 / $30.00 | $0.50 | $10.00 / $45.00 | $2.50 / $15.00 | $12.50 / $75.00 |

API 速率限制（按 RPM、RPD、TPM、TPD、IPM 以及每个向量存储 300 RPM 的限额衡量）根据受支持国家与地区的累计额度购买金额，分为四个命名使用层级：[7]

- **Free 层级**：仅限允许的地区；月度使用上限为 $100。[7]
- **Build 层级**：累计购买额度满 $5 解锁；月度使用上限为 $500。[7]
- **Launch 层级**：累计购买额度满 $100 解锁；月度使用上限为 $5,000。[7]
- **Grow 层级**：累计购买额度满 $500 解锁；月度使用上限为 $200,000。[7]

在网络数据抓取与实时搜索方面，OpenAI 运营四个相互独立的 HTTP 用户代理，分别配备独立的 `robots.txt` 控制规则和公开 JSON IP 白名单：`GPTBot/1.4`（`openai.com/gptbot.json`，用于抓取公开网页内容以训练生成式 AI 基础模型）、`OAI-SearchBot/1.4`（`openai.com/searchbot.json`，用于为 ChatGPT 搜索结果索引网页且不用于训练模型）、`OAI-AdsBot/1.0`（`openai.com/adsbot.json`，用于验证作为 ChatGPT 广告提交的落地页的政策合规性与相关性且不用于训练模型）以及 `ChatGPT-User/1.0`（`openai.com/chatgpt-user.json`，由用户实时查询和 Custom GPT 操作触发）。[7]

在开源生态治理方面，OpenAI 于 2025 年 12 月 9 日与 Anthropic 和 Block 共同创立了 Linux 基金会旗下的智能体 AI 基金会（Agentic AI Foundation，简称 AAIF），捐赠 `AGENTS.md` 代码仓库指南规范作为首批创始项目，并与亚马逊云科技（Amazon Web Services）、Anthropic、Block、彭博（Bloomberg）、Cloudflare、谷歌（Google）和微软一同成为 AAIF 白金会员。[9]

## 常见问题

### 2025 年 10 月资本重组后，OpenAI 的组织架构是怎样的？

自 2025 年 10 月 28 日起，OpenAI 由非营利组织 OpenAI 基金会和受其控制的营利性公益公司 OpenAI Group PBC 组成。OpenAI 基金会拥有排他性特别投票权，可任命和撤换 OpenAI Group PBC 的全部董事，在基金会层面保留由齐科·科尔特博士担任主席的安全与保障委员会，并持有 OpenAI Group 26% 的普通股股权（完成时估值约 1,300 亿美元）及一份在公司股价增长超过 10 倍时可获得额外股份的 15 年期认股权证。 [2]

### 微软持有 OpenAI 多少股权？

根据 OpenAI 在 2025 年 10 月资本重组后发布的架构披露，微软持有 OpenAI Group PBC 约 27% 的股权，OpenAI 基金会持有 26%（外加一份长期估值认股权证），现任和前任员工及其他投资者持有其余 47%。所有股东均持有按比例分享 OpenAI Group 价值的常规普通股。 [2]

### 2026 年底 OpenAI API 阵容中的主要模型有哪些？

OpenAI 的旗舰 API 模型包括面向复杂推理与编程的 GPT-6.2 Astra（短上下文输入/输出每百万 Token $8/$40）、面向日常编程与可扩展智能体的 GPT-6.2 Sol（$2/$10）、面向快速视觉推理与计算机操控的 GPT-6.1 Terra（$1/$5）以及面向高吞吐工作负载的 GPT-6 Luna（$0.10/$0.50）。OpenAI 还提供领域专用模型（GPT-6 Cyber 和面向生命科学的 GPT-Rosalind）、多模态模型（GPT-Image-2.6 Sunburst/Flare、GPT-Live-1.1、GPT-Realtime-2.1）以及开放权重模型（gpt-oss-120b 和 gpt-oss-20b）。 [6]

### OpenAI 的网络爬虫（GPTBot、OAI-SearchBot、OAI-AdsBot 和 ChatGPT-User）之间有什么区别？

OpenAI 按功能拆分网络爬虫，以便网站所有者设置独立的 robots.txt 规则：GPTBot/1.4 抓取可能用于训练生成式 AI 基础模型的内容；OAI-SearchBot/1.4 索引网站以便在 ChatGPT 搜索结果中展示；OAI-AdsBot/1.0 验证作为 ChatGPT 广告提交的落地页的政策合规性与相关性（不用于训练模型）；ChatGPT-User/1.0 则在用户要求 ChatGPT 或 Custom GPT 访问特定 URL 时按需抓取页面。 [7]
