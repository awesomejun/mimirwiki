## Cloudflare 应用服务方案价格

Cloudflare 在其定价页面的「Network & CDN」标签下公布了四档应用服务方案：Free、Pro、Business 和 Contract。[5] 截至 2026-11-21，该页面以美元标示的价格如下。[5]

| 方案 | 标示价格 | 计费条件 | Cloudflare 说明的适用场景 |
| --- | --- | --- | --- |
| Free | 每月 0 美元 | 免费 | 个人或兴趣项目 |
| Pro | 每月 20 美元 | 按年计费；按月计费为每月 25 美元 | 专业网站 |
| Business | 每月 200 美元 | 按年计费；按月计费为每月 250 美元 | 在线运营的小型企业 |
| Contract | 定制报价 | 按年计费 | 关键任务型应用 |

Cloudflare 的 Pro 和 Business 方案价格因计费周期而异：Pro 按月计费的标示价格比按年计费高出每月 5 美元，Business 则高出每月 50 美元。[5] Contract 级别未公开价格，定价页面上的对应链接指向 Cloudflare 的企业套餐页面。[5] 同一页面的方案对比表明确将 DNS、不限流量（unmetered）DDoS 防护、[内容分发网络](https://mimirwiki.com/zh/wiki/content-delivery-network)（CDN）、Universal SSL 证书和 Web 应用防火墙（WAF）列为全部四档方案的包含项，并将 100% 正常运行时间服务级别协议（SLA）仅列于 Business 和 Contract 级别。[5]

截至 2026-11-21，Cloudflare 的定价页面还列出了三档 SASE 与 Zero Trust 方案：支持最多 50 名用户的免费 Free 方案（0 美元）、每用户每月 7 美元的 Pay-as-you-go 方案，以及按用户定制年费的 Contract 方案。[5]

## Cloudflare Workers 方案、限额与定价

[Cloudflare Workers](https://mimirwiki.com/zh/wiki/cloudflare-workers) 是 Cloudflare 开发者平台的无服务器计算产品，提供 Workers Free 方案以及每账户每月最低收费 5 美元的 Workers Paid 方案。[6] Workers Paid 的用量采用 Standard 计费模式，按请求次数和 CPU 时间计费，不收取持续时间费用，也不额外收取数据传输（出站流量）或带宽费用。[6] 下表数据于 2026-11-21 读取自 Cloudflare 官方文档，其中定价行取自 Workers 定价页面，限额行取自 Workers 限额页面。[6][7]

| 项目 | Workers Free | Workers Paid |
| --- | --- | --- |
| 请求数 | 每日 100,000 次 | 每月包含 1,000 万次，超出部分每百万次 0.30 美元 |
| CPU 时间 | 每次调用 10 ms | 每月包含 3,000 万 CPU ms，超出部分每百万 CPU ms 0.02 美元 |
| 单次 HTTP 请求最大 CPU 时间 | 10 ms | 5 分钟（默认 30 秒） |
| 每个隔离实例（isolate）内存 | 128 MB | 128 MB |
| 单次请求子请求数 | 50 次 | 10,000 次 |
| Worker 大小 | 64 MiB | 64 MiB |
| 每账户 Worker 数量 | 100 个 | 500 个 |
| 每账户 Cron Triggers 数量 | 5 个 | 1,000 个 |

Cloudflare Workers Free 的每日请求限额在 UTC 午夜重置，当 Worker 超出限额时，Cloudflare 会返回 Error 1027。[7] Cloudflare 不对 Worker 发起的子请求收费。[6]

Cloudflare 的开发者文档也以面向自动化读取程序的格式发布：截至 2026-11-21，Workers 文档页面链接至 [llms.txt](https://mimirwiki.com/zh/wiki/llms-txt) 索引、`llms-full.txt` 文件以及各页面的 Markdown 版本，文档导航栏亦提供指向 GitHub 上 Cloudflare [Model Context Protocol](https://mimirwiki.com/zh/wiki/model-context-protocol) 服务器的链接。[6]

## Cloudflare 的 AI 爬虫控制与 Web Bot Auth

Cloudflare 陆续发布了一系列控制功能，使网站所有者能够决定 AI 爬虫如何访问通过其网络分发的内容。[11][14] 2025 年 7 月 1 日，Cloudflare 宣布所有新域名在注册时都将被询问是否允许 AI 爬虫，并将此项变更描述为默认拦截未经许可或未支付报酬即访问内容的 AI 爬虫。[11]

同日，Cloudflare 宣布推出 pay per crawl 的封闭测试版。[12] 在 pay per crawl 机制下，网站所有者可为整个域名设定统一的按请求收费单价，爬虫需在请求头中表明付费意愿，否则将收到 HTTP 402 Payment Required 响应，并由 Cloudflare 担任记录商户（merchant of record）。[12]

[Web Bot Auth](https://mimirwiki.com/zh/wiki/web-bot-auth) 是 Cloudflare 用于验证爬虫与智能体身份的机器人认证方案，基于 HTTP Message Signatures 构建。[13] Cloudflare 于 2025 年 5 月发布了使用 HTTP Message Signatures 识别机器人和智能体的提案以及 Web Bot Auth 的 IETF 草案，并于 2025 年 7 月 1 日宣布将 HTTP Message Signatures 整合至 Verified Bots Program 中。[13] 参与 pay per crawl 的爬虫需要生成 Ed25519 密钥对，将公钥发布到托管目录，并使用 HTTP Message Signatures 对每次请求进行签名。[12]

2026 年 7 月 1 日，Cloudflare 向包括 Free 级别在内的所有客户推出了按三种行为管理 AI 流量的控制功能：Search、Agent 和 Training。[14] 在同一公告中，Cloudflare 表示自 2026 年 9 月 15 日起，新域名在展示广告的页面上将默认拦截 Training 和 Agent 流量，同时保持允许 Search 流量。[14]

2026 年 9 月 15 日，Cloudflare 宣布推出 Disallow AI Training 设置，该设置会在 robots.txt 中发布禁止训练偏好，对 Cloudflare 认定为 Accountable 的混合用途爬虫继续允许其用于搜索，并拦截其他训练爬虫。[15] 公告指出 Apple、Google 和 Microsoft 已遵守或承诺遵守该设置，并说明原有的 Block AI Bots 选项将被弃用，由 Search、Training 和 Agent 控制功能取代。[15]

## 常见问题

### Cloudflare Pro 方案的价格是多少？

截至 2026-11-21，Cloudflare 定价页面显示 Pro 方案按年计费为每月 20 美元，按月计费为每月 25 美元。Business 方案按年计费为每月 200 美元，按月计费为每月 250 美元。Free 方案为 0 美元，最高级别的 Contract 方案采用按年计费的定制报价。 [5]

### Cloudflare R2 是否收取出站流量费？

不收取。截至 2026-11-21，Cloudflare R2 定价页面明确声明所有存储类别均不收取出站带宽费用。R2 按存储容量（Standard 存储每 GB-月 0.015 美元）以及 Class A 和 Class B 操作计费，连接到存储桶的其他计量服务可能会单独收费。 [8]

### Cloudflare Workers 免费方案有哪些限额？

截至 2026-11-21，Workers Free 方案允许每日 100,000 次请求、每次调用 10 毫秒 CPU 时间、128 MB 内存以及每次请求 50 次子请求。Workers Paid 方案每月最低收费 5 美元，包含每月 1,000 万次请求和 3,000 万 CPU 毫秒。 [6][7]

### Cloudflare 是否默认拦截 AI 爬虫？

2025 年 7 月 1 日，Cloudflare 宣布所有新域名在注册时都将被询问是否允许 AI 爬虫。2026 年 7 月 1 日，该公司为所有方案增加了独立的 Search、Agent 和 Training 控制选项，并宣布自 2026 年 9 月 15 日起，新域名在展示广告的页面上将默认拦截 Training 和 Agent 流量，同时允许 Search 流量。网站所有者可以修改这些设置。 [11][14]

### Cloudflare 是否通过了 SOC 2 和 ISO 27001 认证？

截至 2026-11-21，Cloudflare 的合规资源页面列出了 SOC 2 Type II、ISO 27001:2022、ISO 27701:2019、PCI DSS 4.0 和 FedRAMP High 等多项认证与鉴证。Cloudflare 说明相关合规证明文档可通过其控制台获取。 [9]

Cloudflare, Inc. 的 A 类普通股自 2019 年 9 月 13 日起在纽约证券交易所上市，股票代码为 NET。该公司以 CIK 0001477333 向美国证券交易委员会（SEC）提交申报文件。 [1][2]

- 2009-11: Cloudflare 完成由 Venrock 和 Pelion Venture Partners 参与的 A 轮融资。 [10]
- 2010-09-27: Cloudflare 在旧金山举办的 TechCrunch Disrupt 大会上公开发布。 [10]
- 2019-09-13: Cloudflare 的 A 类普通股在纽约证券交易所上市，股票代码为 NET。 [2]
- 2025-05: Cloudflare 发布 HTTP Message Signatures 提案及 Web Bot Auth 的 IETF 草案。 [13]
- 2025-07-01: Cloudflare 宣布新域名在注册时将被询问是否允许 AI 爬虫，并宣布推出 pay per crawl 封闭测试版。 [11][12]
- 2026-02-26: Cloudflare 提交 2025 财年 Form 10-K，报告营收 21.679 亿美元。 [1][2]
- 2026-04-01: Alissa Starzak 接替 Douglas Kramer 出任 Cloudflare 首席法务官兼公司秘书。 [3]
- 2026-05-07: Cloudflare 披露一项预计裁员约 20% 的重组计划。 [4]
- 2026-07-01: Cloudflare 面向所有客户推出针对 AI 流量的 Search、Agent 和 Training 控制功能。 [14]
- 2026-09-15: Cloudflare 宣布推出面向混合用途爬虫的 Disallow AI Training 设置。 [15]
