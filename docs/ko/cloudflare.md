# Cloudflare

> Cloudflare, Inc.는 미국 샌프란시스코에 본사를 둔 기술 기업으로, 뉴욕증권거래소에 종목 기호 NET으로 상장되어 있다. 전 세계 네트워크를 통해 CDN, DNS, DDoS 방어, 웹 애플리케이션 방화벽, Zero Trust, 그리고 Workers와 R2 같은 서버리스 개발자 서비스를 제공한다. Form 10-K에 따르면 2025 회계연도 매출은 21억 6,790만 달러, 정규직 직원은 5,156명이다.

Cloudflare, Inc.는 2009년 7월 미국 델라웨어주에서 법인으로 설립되어 캘리포니아주 샌프란시스코에 본사를 둔 기술 기업으로, 전 세계에 걸친 네트워크를 운영하며 애플리케이션 보안 및 성능 서비스, SASE(Secure Access Service Edge) 플랫폼, 그리고 Cloudflare Workers와 R2 오브젝트 스토리지를 포함한 개발자 플랫폼을 제공한다. Class A 보통주는 2019년 9월 13일부터 뉴욕증권거래소(NYSE)에 종목 기호 NET으로 상장되어 있다. 2025년 12월 31일에 끝난 회계연도에 Cloudflare는 매출 21억 6,790만 달러와 정규직 직원 5,156명을 보고했다. Cloudflare는 가격이 공개된 Free, Pro, Business 요금제와 가격을 개별 산정하는 Contract 등급을 함께 제시한다.

## Cloudflare 법인 정보와 SEC 공시

Cloudflare, Inc.는 미국 증권거래위원회(SEC)에 중앙색인키(CIK) 0001477333으로 등록되어 있으며, 설립 주는 델라웨어, 회계연도 종료일은 12월 31일, 표준산업분류(SIC) 코드는 7372(패키지 소프트웨어)이다.[1] Cloudflare는 2009년 7월 델라웨어주에서 법인으로 설립되었고, 본사 주소는 캘리포니아주 샌프란시스코의 101 Townsend Street(우편번호 94107)이다.[2] Cloudflare의 공식 회사 연혁은 창립 연도를 2009년으로, 창립자를 Matthew Prince, Michelle Zatlyn, Lee Holloway로 밝히고 있으며, 서비스를 2010년 9월 27일 샌프란시스코에서 열린 TechCrunch Disrupt 콘퍼런스에서 공개 출시했다고 설명한다.[10]

Cloudflare의 Class A 보통주는 2019년 9월 13일부터 뉴욕증권거래소(NYSE)에 종목 기호 NET으로 상장되어 있다.[2] Cloudflare의 보통주는 두 종류이며 Class B 주식은 주당 10개, Class A 주식은 주당 1개의 의결권을 가진다.[2]

Cloudflare의 가장 최근 연차보고서는 2025년 12월 31일에 끝난 회계연도(2025 회계연도)의 Form 10-K이며, [SEC EDGAR](https://mimirwiki.com/ko/wiki/sec-edgar)에는 2026년 2월 26일에 제출된 것으로 올라 있다.[1] 이 보고서에 실린 주요 수치는 다음과 같다.[2]

| 항목 | 2025 회계연도 수치 |
| --- | --- |
| 매출 | 21억 6,790만 달러(2024 회계연도 대비 30% 증가) |
| 순손실 | 1억 230만 달러 |
| 정규직 직원 수(2025-12-31 기준) | 5,156명, 이 중 2,452명은 미국 외 지역 근무 |
| 유료 고객 수(2025-12-31 기준) | 190개국 이상에서 약 332,000곳 |

이 직원 수는 Cloudflare가 2026년 5월 7일 공시한 구조조정 계획 이전의 수치이며, Cloudflare는 이 계획으로 인력을 약 20% 줄이고 1억 4,000만 달러에서 1억 5,000만 달러의 비용이 발생할 것으로 예상했다.[4]

2026년 4월 1일 기준으로 Cloudflare의 Form 10-K/A에는 임원(executive officer)으로 Matthew Prince(최고경영자 겸 이사회 공동의장), Michelle Zatlyn(사장 겸 이사회 공동의장), Thomas Seifert(최고재무책임자), Alissa Starzak(최고법무책임자 겸 법인 서기) 네 명이 기재되어 있다.[3] Alissa Starzak는 Douglas Kramer가 2026년 3월 31일부로 최고법무책임자에서 물러난 뒤 2026년 4월 1일에 취임했다.[3]

## Cloudflare 애플리케이션 서비스 요금제 가격

Cloudflare는 가격 페이지의 Network & CDN 탭에 애플리케이션 서비스 요금제 네 가지, 곧 Free, Pro, Business, Contract를 제시한다.[5] 2026-11-21 기준으로 이 페이지에 표시된 가격은 미국 달러로 다음과 같다.[5]

| 요금제 | 표시 가격 | 결제 조건 | Cloudflare가 밝힌 용도 |
| --- | --- | --- | --- |
| Free | 월 0달러 | 무료 | 개인 또는 취미 프로젝트 |
| Pro | 월 20달러 | 연간 결제 기준, 월간 결제 시 월 25달러 | 전문 웹사이트 |
| Business | 월 200달러 | 연간 결제 기준, 월간 결제 시 월 250달러 | 온라인으로 운영하는 소규모 사업체 |
| Contract | 개별 산정 | 연간 결제 | 핵심 업무용 애플리케이션 |

Cloudflare Pro와 Business의 가격은 결제 주기에 따라 달라서, 월간 결제 가격이 연간 결제 가격보다 Pro는 월 5달러, Business는 월 50달러 높게 표시되어 있다.[5] Contract 등급은 가격이 공개되어 있지 않으며, 가격 페이지의 해당 링크는 Cloudflare의 엔터프라이즈 패키지 페이지로 연결된다.[5] 같은 페이지의 요금제 비교표는 DNS, 무제한(unmetered) DDoS 방어, [콘텐츠 전송 네트워크](https://mimirwiki.com/ko/wiki/content-delivery-network)(CDN), Universal SSL 인증서, 웹 애플리케이션 방화벽(WAF)을 네 요금제 모두에 포함된 것으로 표시하고, 100% 가동 시간 서비스 수준 계약(SLA)은 Business와 Contract 등급에만 기재한다.[5]

Cloudflare의 가격 페이지에는 2026-11-21 기준으로 SASE 및 Zero Trust 요금제 세 가지도 나와 있는데, 사용자 50명까지 0달러인 Free, 사용자당 월 7달러인 Pay-as-you-go, 사용자당 연간 가격을 개별 산정하는 Contract이다.[5]

## Cloudflare Workers 요금제, 한도, 가격

[Cloudflare Workers](https://mimirwiki.com/ko/wiki/cloudflare-workers)는 Cloudflare 개발자 플랫폼의 서버리스(serverless) 컴퓨팅 제품으로, Workers Free 요금제와 계정당 월 최소 5달러가 청구되는 Workers Paid 요금제로 제공된다.[6] Workers Paid의 사용량은 Standard 사용량 모델을 따르며, 요청 수와 CPU 시간을 기준으로 과금하고 실행 지속 시간(duration)에는 요금이 없으며 데이터 전송(egress)이나 대역폭에 대한 추가 요금도 없다.[6] 아래 수치는 2026-11-21에 Cloudflare 문서에서 확인한 것으로, 가격 관련 행은 Workers 가격 페이지에서, 한도 관련 행은 Workers 한도 페이지에서 가져왔다.[6][7]

| 항목 | Workers Free | Workers Paid |
| --- | --- | --- |
| 요청 수 | 하루 100,000건 | 월 1,000만 건 포함, 초과분 100만 건당 0.30달러 |
| CPU 시간 | 호출당 10ms | 월 3,000만 CPU ms 포함, 초과분 100만 CPU ms당 0.02달러 |
| HTTP 요청당 최대 CPU 시간 | 10ms | 5분(기본값 30초) |
| 아이솔레이트(isolate)당 메모리 | 128MB | 128MB |
| 요청당 서브리퀘스트(subrequest) | 50건 | 10,000건 |
| Worker 크기 | 64MiB | 64MiB |
| 계정당 Worker 수 | 100개 | 500개 |
| 계정당 Cron Trigger 수 | 5개 | 1,000개 |

Cloudflare Workers Free의 일일 요청 한도는 UTC 자정에 초기화되며, Worker가 한도를 넘으면 Cloudflare는 Error 1027을 반환한다.[7] Worker가 보내는 서브리퀘스트에는 요금이 청구되지 않는다.[6]

Cloudflare의 개발자 문서는 자동화된 독자를 위한 형식으로도 제공되는데, 2026-11-21 기준으로 Workers 문서 페이지는 [llms.txt](https://mimirwiki.com/ko/wiki/llms-txt) 색인, `llms-full.txt` 파일, 각 페이지의 Markdown 버전으로 연결되며, 문서 내비게이션에는 GitHub에 있는 Cloudflare의 [Model Context Protocol](https://mimirwiki.com/ko/wiki/model-context-protocol)(MCP) 서버로 가는 링크가 있다.[6]

## Cloudflare R2, D1, Workers KV, Queues, Durable Objects 가격

[Cloudflare R2](https://mimirwiki.com/ko/wiki/cloudflare-r2)는 Cloudflare의 오브젝트 스토리지(object storage) 서비스이며, 가격 페이지는 모든 스토리지 클래스에서 이그레스(egress, 외부로 나가는 데이터 전송) 대역폭 요금이 없다고 밝힌다.[8] R2는 저장된 데이터의 양과 두 종류의 작업(operation)에 요금을 매기며, 데이터 검색(retrieval) 요금은 Infrequent Access 스토리지 클래스에만 적용된다.[8] 아래 가격은 2026-11-21에 확인한 것이다.[8]

| R2 항목 | Standard 스토리지 | Infrequent Access 스토리지 |
| --- | --- | --- |
| 저장 용량 | GB-월당 0.015달러 | GB-월당 0.01달러 |
| Class A 작업 | 요청 100만 건당 4.50달러 | 요청 100만 건당 9.00달러 |
| Class B 작업 | 요청 100만 건당 0.36달러 | 요청 100만 건당 0.90달러 |
| 데이터 검색 | 없음 | GB당 0.01달러 |
| 인터넷으로 나가는 이그레스 | 무료 | 무료 |

Cloudflare R2의 무료 제공량은 매월 저장 용량 10GB-월, Class A 요청 100만 건, Class B 요청 1,000만 건이며 Standard 스토리지에만 적용된다.[8] Cloudflare는 R2 버킷에 연결한 다른 종량제 서비스에서는 별도 요금이 발생할 수 있다고 안내한다.[8]

Cloudflare는 개발자 플랫폼의 다른 데이터 제품 가격을 Workers 가격 페이지에 함께 싣는다.[6] 2026-11-21에 표시된 제공량과 요율은 다음과 같다.[6]

| 제품 및 지표 | Workers Free | Workers Paid |
| --- | --- | --- |
| D1 읽은 행 수 | 하루 500만 행 | 월 250억 행 포함, 초과분 100만 행당 0.001달러 |
| D1 기록한 행 수 | 하루 100,000행 | 월 5,000만 행 포함, 초과분 100만 행당 1.00달러 |
| D1 저장 용량 | 총 5GB | 5GB 포함, 초과분 GB-월당 0.75달러 |
| Workers KV 키 읽기 | 하루 100,000건 | 월 1,000만 건 포함, 초과분 100만 건당 0.50달러 |
| Workers KV 키 쓰기 | 하루 1,000건 | 월 100만 건 포함, 초과분 100만 건당 5.00달러 |
| Workers KV 저장 데이터 | 1GB | 1GB 포함, 초과분 GB-월당 0.50달러 |
| Queues 표준 작업 | 하루 10,000건 | 월 100만 건 포함, 초과분 100만 건당 0.40달러 |
| Durable Objects 요청 | 하루 100,000건 | 월 100만 건 포함, 초과분 100만 건당 0.15달러 |
| Durable Objects 실행 시간 | 하루 13,000GB-s | 월 400,000GB-s 포함, 초과분 100만 GB-s당 12.50달러 |

Cloudflare Workers Free 요금제에서는 SQLite 스토리지 백엔드를 쓰는 Durable Objects만 사용할 수 있다.[6] Cloudflare는 D1과 Queues에 데이터 전송(egress)이나 대역폭 요금이 없다고 밝힌다.[6]

## Cloudflare 네트워크 규모와 컴플라이언스 인증

Cloudflare의 네트워크는 2026년 2월 26일에 제출된 2025 회계연도 Form 10-K에서 125개가 넘는 국가의 330개가 넘는 도시에 걸쳐 있다고 기술되어 있다.[1][2] 2026-11-21 기준으로 Cloudflare의 네트워크 페이지는 주요 수치로 335개 이상의 도시, 125개 이상의 국가, 13,000개 이상의 네트워크 상호 연결(interconnection)을 표시했고, 같은 페이지의 데이터 센터 위치 목록에는 8개 지역 348개 도시라고 적혀 있었다.[16] 이 페이지는 또한 전 세계 인터넷 이용 인구의 95%가 Cloudflare 데이터 센터에서 50밀리초 이내에 있다고 밝힌다.[16]

Cloudflare는 컴플라이언스 자료 페이지에 인증 및 검증 내역을 나열하고, 관련 컴플라이언스 문서는 Cloudflare 대시보드에서 받을 수 있다고 안내한다.[9] 2026-11-21 기준으로 이 페이지에 실린 항목 가운데 일부는 다음과 같다.[9]

| 항목 | Cloudflare가 제시한 설명 |
| --- | --- |
| SOC 2 Type II | AICPA 신뢰 서비스 기준(Trust Services Criteria)에 따른 보안, 기밀성, 가용성 통제 검증 |
| ISO 27001:2022 | 정보보호 관리체계(ISMS) 인증 |
| ISO 27701:2019 | 개인정보 관리체계(PIMS) 인증 |
| ISO 27018:2019 | 클라우드에서 처리되는 개인정보의 보호 |
| PCI DSS 4.0 | 결제 카드 산업 데이터 보안 표준(PCI DSS) 준수 증명서(AoC) |
| FedRAMP High | 미국 연방 위험 및 인가 관리 프로그램(FedRAMP) |

Cloudflare의 컴플라이언스 자료 페이지에는 ISO 27017:2015, GovRAMP, C5:2020, ENS, IRAP, ISMAP, HIPAA, Cyber Essentials, CSA STAR도 올라 있다.[9]

## Cloudflare의 AI 크롤러 제어와 Web Bot Auth

Cloudflare는 사이트 소유자가 자사 네트워크를 통해 제공되는 콘텐츠에 AI 크롤러(crawler)가 접근하는 방식을 정할 수 있도록 여러 제어 기능을 차례로 발표했다.[11][14] 2025년 7월 1일 Cloudflare는 새로 등록하는 모든 도메인에 가입 시점부터 AI 크롤러 허용 여부를 묻겠다고 발표했고, 이를 허가나 보상 없이 콘텐츠에 접근하는 AI 크롤러를 기본값으로 차단하는 조치라고 설명했다.[11]

같은 날 Cloudflare는 pay per crawl을 비공개 베타로 발표했다.[12] pay per crawl에서는 사이트 소유자가 도메인 전체에 요청당 단일 가격을 정하고, 크롤러는 요청 헤더로 결제 의사를 밝히거나 HTTP 402 Payment Required 응답을 받으며, Cloudflare가 판매 주체(merchant of record) 역할을 한다.[12]

[Web Bot Auth](https://mimirwiki.com/ko/wiki/web-bot-auth)는 Cloudflare가 크롤러와 에이전트의 신원을 확인하는 데 쓰는 봇 인증 방식으로, HTTP 메시지 서명(HTTP Message Signatures)에 기반한다.[13] Cloudflare는 2025년 5월 봇과 에이전트를 HTTP 메시지 서명으로 식별하자는 제안과 Web Bot Auth IETF 초안을 공개했고, 2025년 7월 1일에는 HTTP 메시지 서명을 Verified Bots Program에 통합한다고 발표했다.[13] pay per crawl에 참여하는 크롤러는 Ed25519 키 쌍을 생성하고 공개 키를 호스팅된 디렉터리에 게시한 뒤 모든 요청에 HTTP 메시지 서명을 붙인다.[12]

2026년 7월 1일 Cloudflare는 AI 트래픽을 Search, Agent, Training이라는 세 가지 행동 유형으로 나누어 관리하는 제어 기능을 Free 등급을 포함한 모든 고객에게 내놓았다.[14] 같은 발표에서 Cloudflare는 2026년 9월 15일부터 새 도메인에는 광고가 표시되는 페이지에서 Training과 Agent 트래픽을 기본값으로 차단하고 Search는 계속 허용하겠다고 밝혔다.[14]

2026년 9월 15일 Cloudflare는 Disallow AI Training 설정을 발표했는데, 이 설정은 robots.txt에 학습 금지 의사를 게시하고, Cloudflare가 Accountable로 지정한 혼합 용도(mixed-use) 크롤러는 검색 목적으로 계속 허용하며, 그 밖의 학습용 크롤러는 차단한다.[15] 이 발표는 해당 설정을 준수하거나 준수하기로 약속한 운영사로 Apple, Google, Microsoft를 들었고, 기존의 Block AI Bots 옵션은 Search, Training, Agent 제어로 대체되어 지원이 중단될 것이라고 밝혔다.[15]

## 자주 묻는 질문

### Cloudflare Pro 요금제는 얼마인가요?

2026-11-21 기준 Cloudflare 가격 페이지에는 Pro 요금제가 연간 결제 시 월 20달러, 월간 결제 시 월 25달러로 표시되어 있습니다. Business 요금제는 연간 결제 시 월 200달러, 월간 결제 시 월 250달러입니다. Free 요금제는 0달러이며, Contract로 표시된 최상위 등급은 가격을 개별 산정하고 연간으로 결제합니다. [5]

### Cloudflare R2는 이그레스(egress) 요금을 부과하나요?

아니요. 2026-11-21 기준 Cloudflare R2 가격 페이지는 모든 스토리지 클래스에서 이그레스 대역폭 요금이 없다고 밝히고 있습니다. R2는 저장 용량(Standard 스토리지 기준 GB-월당 0.015달러)과 Class A, Class B 작업에 요금을 부과하며, 버킷에 연결한 다른 종량제 서비스에서는 별도 요금이 발생할 수 있습니다. [8]

### Cloudflare Workers 무료 요금제의 한도는 어떻게 되나요?

2026-11-21 기준 Workers Free 요금제는 하루 요청 100,000건, 호출당 CPU 시간 10밀리초, 메모리 128MB, 요청당 서브리퀘스트 50건까지 허용합니다. Workers Paid 요금제는 월 최소 5달러가 청구되며 월 1,000만 건의 요청과 3,000만 CPU 밀리초가 포함됩니다. [6][7]

### Cloudflare는 AI 크롤러를 기본적으로 차단하나요?

Cloudflare는 2025년 7월 1일, 새로 등록하는 모든 도메인에 가입 시점부터 AI 크롤러 허용 여부를 묻겠다고 발표했습니다. 2026년 7월 1일에는 모든 요금제에 Search, Agent, Training 제어를 따로 추가했고, 2026년 9월 15일부터 새 도메인에는 광고가 표시되는 페이지에서 Training과 Agent 트래픽을 기본값으로 차단하고 Search는 허용하겠다고 밝혔습니다. 사이트 소유자는 이 설정을 변경할 수 있습니다. [11][14]

### Cloudflare는 SOC 2와 ISO 27001 인증을 받았나요?

2026-11-21 기준 Cloudflare의 컴플라이언스 자료 페이지에는 SOC 2 Type II, ISO 27001:2022, ISO 27701:2019, PCI DSS 4.0, FedRAMP High를 비롯한 인증 및 검증 내역이 올라 있습니다. Cloudflare는 관련 컴플라이언스 문서를 대시보드에서 받을 수 있다고 안내합니다. [9]

### Cloudflare의 주식 종목 기호는 무엇이고 어디에 상장되어 있나요?

Cloudflare, Inc.의 Class A 보통주는 2019년 9월 13일부터 뉴욕증권거래소에 종목 기호 NET으로 상장되어 있습니다. 회사는 미국 증권거래위원회(SEC)에 CIK 0001477333으로 공시 자료를 제출합니다. [1][2]
