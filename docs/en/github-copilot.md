# GitHub Copilot

> GitHub Copilot is an AI coding assistant and agent platform developed by GitHub, whose cloud services appear in Microsoft Corporation's Intelligent Cloud segment. Launched in technical preview on June 29, 2021 and generally available on June 21, 2022, it operates across IDEs, terminals, desktop apps, and github.com. As of 2026-11-23, GitHub Copilot offers multi-vendor models and AI Credits billing.

GitHub Copilot is an artificial intelligence coding assistant and agent platform developed by GitHub, whose cloud and on-premises offerings are reported within Microsoft Corporation's Intelligent Cloud segment. GitHub introduced GitHub Copilot in a limited technical preview on June 29, 2021 using OpenAI Codex, made it generally available to individual developers on June 21, 2022, and launched the GitHub Copilot Free tier on December 18, 2024. As of 2026-11-23, GitHub Copilot runs across code editors, the command line, a desktop application, github.com, GitHub Mobile, Slack, and Microsoft Teams, supporting AI models from OpenAI, Anthropic, Google, Microsoft, xAI, and Kimi alongside user-supplied API keys and local model runtimes. As of 2026-11-23, GitHub offers individual plans (Free, Student, Pro at $10 per month, Pro+ at $39 per month, and Max at $100 per month) and organization or enterprise plans (Business at $19 per seat per month, Enterprise at $39 per seat per month, and Copilot access), with metered features billed through GitHub AI Credits at $0.01 USD per credit.

**Also known as:** Copilot, GitHub Copilot Pro, GitHub Copilot Business, GitHub Copilot Enterprise

## GitHub Copilot launch history and Microsoft reporting context

GitHub Copilot was introduced by GitHub in a limited technical preview on June 29, 2021, developed in collaboration with [OpenAI](https://mimirwiki.com/wiki/openai) and powered by [OpenAI Codex](https://mimirwiki.com/wiki/openai-codex).[7] At launch, GitHub described Copilot as an AI pair programmer that drew context from open code to suggest whole lines or functions, trained on a dataset containing a high concentration of public source code and working across multiple languages, especially Python, JavaScript, TypeScript, Ruby, and Go.[7]

On June 21, 2022, GitHub made GitHub Copilot generally available to all individual developers as an editor extension priced at $10 USD per month or $100 USD per year, with a free trial and free access for verified students and maintainers of popular open source projects.[8] On December 18, 2024, Thomas Dohmke (Chief Executive Officer of GitHub from 2021 to 2025) announced GitHub Copilot Free, integrated into Visual Studio Code and accessible from the GitHub dashboard, following GitHub reaching 150 million developers on the platform.[9] At launch, Copilot Free provided 2,000 code completions and 50 chat messages per month, supported [Anthropic](https://mimirwiki.com/wiki/anthropic)'s [Claude](https://mimirwiki.com/wiki/claude) 3.5 Sonnet and OpenAI's GPT-4o, enabled multi-file edits and third-party agents, and left free unlimited Copilot Pro access for students, educators, and open source maintainers unchanged.[9]

In Microsoft Corporation's Form 10-K for the fiscal year ended June 30, 2026 (SEC Central Index Key 0000789019 on [SEC EDGAR](https://mimirwiki.com/wiki/sec-edgar)), GitHub is described as providing cloud and on-premises offerings for developers to manage code and incorporate AI and agent-based tools across the software development lifecycle.[1] Microsoft reports GitHub cloud services within its Intelligent Cloud segment under Server products and cloud services, and groups GitHub cloud services revenue inside the Azure and other cloud services revenue growth metric without separately disclosing standalone GitHub Copilot revenue in those excerpts.[1] For the fiscal year ended June 30, 2026, Microsoft reported the following consolidated results in its Form 10-K.[1]

## GitHub Copilot plans and pricing

GitHub Copilot is distributed through five individual plans and three organization or enterprise plans as of 2026-11-23.[2][5] GitHub states that all plans include Copilot CLI and the Copilot app, and that GitHub Copilot is not available for GitHub Enterprise Server.[2] Organization and enterprise subscriptions are available to organizations on GitHub Free or GitHub Team plans, as well as organizations and enterprises on GitHub Enterprise Cloud, while Copilot Enterprise requires GitHub Enterprise Cloud.[2][3]

The table below compiles plan prices, monthly credit allowances, and model tiers from GitHub Docs and the GitHub Copilot plans page as of 2026-11-23.[2][3][5]

| Plan | Audience | Listed price | Monthly GitHub AI Credits allowance | Model access and key distinctions |
| --- | --- | --- | --- | --- |
| Copilot Free | Individual | $0 | Limited allowance (2,000 inline completions per month) | Auto model selection only (Docs); Fusion Standard; Community Support |
| Copilot Student | Individual (verified students) | $0 | Limited allowance | Auto model selection only (Docs); excludes third-party agents |
| Copilot Pro | Individual | $10 USD per month (free for some users) | 1,000 base credits ($10 base plus $5 flex allotment, $15 total) | Unlimited completions and next edit suggestions; model selection; Copilot in the cloud; code review |
| Copilot Pro+ | Individual | $39 USD per month | 3,900 base credits ($39 base plus $31 flex allotment, $70 total) | Premium models including Opus; Fusion Standard, High, and Max; audit logs |
| Copilot Max | Individual | $100 USD per month | 10,000 base credits ($100 base plus $100 flex allotment, $200 total) | Priority access to new models and features; highest individual allowance |
| Copilot Business | Organization / Enterprise | $19 USD per granted seat per month | 1,900 credits per user per month (pooled) | Broad model catalog / premium models; centralized management and policy control |
| Copilot Enterprise | Enterprise (GitHub Enterprise Cloud) | $39 USD per granted seat per month | 3,900 credits per user per month (pooled) | Priority access to new models and features; all Copilot Business capabilities |
| Copilot access | Eligible enterprises | $0 (GitHub Enterprise Cloud licensed users) or $10 USD per user per month (Copilot Standalone) | No included allowance (metered from first use) | Same feature and model eligibility as Copilot Enterprise |

On the individual plans comparison page as of 2026-11-23, GitHub marks pooled usage, enterprise-grade security, IP indemnity, user management on github.com, usage metrics, and SAML SSO authentication as excluded from Free, Pro, Pro+, and Max.[5] GitHub's Pro summary card lists third-party agents (Claude Code and Codex) starting on Pro, while the Copilot in the cloud feature matrix on the same page lists cloud delegation to third-party coding agents such as Claude by Anthropic and OpenAI Codex (Preview) as included on Pro+ and Max.[5]

## GitHub Copilot AI Credits and billing model

GitHub Copilot uses GitHub AI Credits to meter interactive and agentic AI usage across plans as of 2026-11-23, with 1 AI credit valued at $0.01 USD.[6] Chat, agent mode, code review, Copilot in the cloud, Copilot CLI, and the Copilot app consume AI credits, and the credit cost of each interaction varies by the selected model and task complexity.[5][6] Inline code completions and next edit suggestions do not consume AI credits and remain unlimited on paid plans, including when an organization user has a $0 USD budget or reaches an enforced spending limit.[3][6]

On individual paid plans as of 2026-11-23, total monthly credits combine a fixed base allotment matching the plan's monthly fee ($10 for Pro, $39 for Pro+, and $100 for Max) with a variable flex allotment ($5 for Pro, $31 for Pro+, and $100 for Max) that GitHub notes may change over time.[5] When users exhaust their monthly allowance, they can wait for the next monthly reset, switch to lightweight models that consume fewer credits per interaction, or set a dollar budget for additional pay-as-you-go usage at $0.01 USD per credit ($10 covers 1,000 credits); purchasing additional credits is excluded on the Free plan.[5][6] Budget tracking in Copilot settings issues usage alerts at 75%, 90%, and 100% of any configured budget.[6]

For organizations and enterprises, Copilot Business and Copilot Enterprise licenses contribute their monthly credit allowances into a shared organization-wide pool, and usage exceeding the pool is billed separately when administrators permit paid overages.[3][5][6] If administrators disallow additional paid usage, Copilot pauses until the next billing cycle.[6] On the Copilot access plan, metered usage is billed from the first use without an included allowance.[3] Each Copilot seat represents a license for one user and must be assigned even when the seat carries a $0 incremental charge; on Copilot access and Copilot Business, enterprise owners can assign seats directly to individuals or to enterprise teams so every team member receives a seat.[3] Data-resident and FedRAMP-compliant Copilot requests carry a 10% model multiplier increase.[3]

Alongside manual model selection, GitHub Copilot includes Copilot Fusion for automatic model routing as of 2026-11-23.[5][6] Fusion Standard (included on Free, Pro, Pro+, and Max) selects one model per task for everyday work, and Fusion Fast (included on Free, Pro, Pro+, and Max) runs only in Visual Studio Code inline chat and is not directly selectable by users.[5] Fusion High (included on Pro+ and Max) targets multi-file changes or complex bug fixes that may use additional model calls, and Fusion Max (included on Pro+ and Max) targets tasks requiring deeper reasoning and analysis.[5]

GitHub Copilot also supports connecting external cloud model providers using user-supplied API keys (bring your own key) and running models locally through Ollama and Foundry Local.[6]

## GitHub Copilot surfaces, IDE support, and agent capabilities

GitHub Copilot operates across editors, terminals, desktop software, web interfaces, and messaging applications as of 2026-11-23, allowing a session started on one surface to continue on another.[5][6] Supported editors and IDE environments listed by GitHub include Visual Studio Code, Visual Studio, JetBrains IDEs, Xcode, Vim, Neovim, Zed, Eclipse, Raycast, and SQL Server Management Studio.[5][6] Beyond editors, GitHub Copilot runs in the terminal through Copilot CLI, through the GitHub Copilot desktop app (including macOS Apple Silicon builds), on github.com, in GitHub Mobile, in Slack, and in Microsoft Teams.[5][6]

Core coding and agent capabilities listed by GitHub as of 2026-11-23 include the following.[5][6]

- **Inline suggestions and next edit suggestions**: Real-time code completions across languages appearing in public repositories, capped at 2,000 completions per month on Free and unlimited on paid plans.[5][6]
- **IDE agent mode**: Available across Free, Pro, Pro+, and Max in Visual Studio Code, Visual Studio, JetBrains IDEs, Eclipse, and Xcode.[5]
- **Copilot in the cloud**: Available on paid plans to research, plan, and write code with or without a pull request, start and track work from issues, pull requests, editors, the agents panel, or third-party project management tools, and run parallel sessions.[5][6]
- **Copilot CLI**: Available on all plans to work from the terminal, delegate tasks to coding agents, make and commit code changes locally or on GitHub, and run in programmatic mode.[2][5]
- **Code review and modernization**: Available on Pro and higher plans for pull request reviews in GitHub, local file diff reviews in code editors, custom review instructions via `instructions.md`, and app modernization for Java and .NET.[5][6]
- **Automations and third-party agents**: Reusable agent tasks can run on demand, on a schedule, or from supported triggers, and supported plans can delegate tasks to third-party coding agents including Claude by Anthropic and [OpenAI Codex](https://mimirwiki.com/wiki/openai-codex).[5][6]

For customization and external tool access, GitHub Copilot supports custom instructions, custom agents, agent skills, Copilot Spaces, Copilot Connectors, plugins, and [Model Context Protocol](https://mimirwiki.com/wiki/model-context-protocol) (MCP) servers in both IDE agent mode and Copilot in the cloud.[5][6]

## GitHub Copilot content filtering, privacy, and enterprise governance

GitHub Copilot applies content filtering across all default AI models as of 2026-11-23, routing both input prompts and output completions through filters for harmful, offensive, or off-topic content.[4] When enabled, GitHub Copilot also runs a public code matching filter with code referencing, which is listed as included across the Free, Pro, Pro+, and Max plans.[4][5]

In its product privacy FAQ as of 2026-11-23, GitHub states that GitHub Copilot processes four categories of personal data depending on the client surface and feature used.[6]

- **User Engagement Data**: Pseudonymous identifiers recorded during interactions, including accepted or dismissed completions, error messages, system logs, and product usage metrics.[6]
- **Prompts**: Chat or code inputs along with surrounding context sent to generate suggestions.[6]
- **Suggestions**: AI-generated code lines or chat responses returned from prompts.[6]
- **Feedback Data**: Real-time user feedback such as thumbs up or thumbs down reactions, optional comments, and support feedback.[6]

For organizations and enterprises, Copilot Business and Copilot Enterprise add centralized seat management, Copilot policy controls, shared credit pools, and administrator spending limits that determine whether overage usage is allowed.[2][3][6] Enterprise plans also encompass capabilities excluded from individual plans, including SAML SSO authentication, user management on github.com, organization usage metrics, enterprise-grade security, and IP indemnity, while audit logs are listed starting with Pro+.[5] Organizations requiring data-resident or FedRAMP-compliant request handling incur a 10% model multiplier increase on those requests.[3]

## Frequently asked questions

### What are the GitHub Copilot plans and prices?

As of 2026-11-23, GitHub offers five individual plans: Free ($0), Student ($0 for verified students), Pro ($10 USD per month), Pro+ ($39 USD per month), and Max ($100 USD per month). For organizations and enterprises, GitHub lists Copilot Business ($19 USD per seat per month), Copilot Enterprise ($39 USD per seat per month), and Copilot access ($0 for licensed GitHub Enterprise Cloud users or $10 USD per user per month for Copilot Standalone, with metered usage billed separately). [2][3][5]

### How do GitHub AI Credits work in GitHub Copilot?

As of 2026-11-23, one GitHub AI Credit equals $0.01 USD, and credits pay for chat, agent mode, code review, Copilot in the cloud, Copilot CLI, and Copilot app usage based on model choice and task complexity. Inline code completions and next edit suggestions do not consume credits and remain unlimited on paid plans. Business and Enterprise seats contribute credits to a shared organization pool, and optional pay-as-you-go spending budgets trigger alerts at 75%, 90%, and 100%. [3][5][6]

### Which AI models does GitHub Copilot support?

As of 2026-11-23, GitHub Copilot supports models from OpenAI (GPT-5 and GPT-6 series), Anthropic (Claude Fable, Haiku, Sonnet, and Opus series), Google (Gemini 3.7, 3.8, and Gemini 4 series), Microsoft (MAI Code series), xAI (Grok 4.5 to 4.7), and Kimi (Kimi K3). Users can let Copilot Fusion route tasks automatically, select a specific model, connect cloud providers with their own API key, or run local models through Ollama and Foundry Local. [4][5][6]

### What does GitHub Copilot Free include?

As of 2026-11-23, GitHub Copilot Free costs $0 with no credit card required and includes 2,000 inline code completions per month, limited chat and agent usage, Copilot CLI, the Copilot app, Copilot Spaces, Model Context Protocol server integration in agent mode, Copilot Fusion Standard, and Community Support. It excludes code review, Copilot in the cloud, pull request creation by assigned agents, and additional credit purchases. [2][5][6][9]

### Which IDEs and platforms support GitHub Copilot?

As of 2026-11-23, GitHub Copilot is available in Visual Studio Code, Visual Studio, JetBrains IDEs, Xcode, Vim, Neovim, Zed, Eclipse, Raycast, and SQL Server Management Studio. It also runs in the terminal via Copilot CLI, in the GitHub Copilot desktop app, on github.com, in GitHub Mobile, in Slack, and in Microsoft Teams, and is not available for GitHub Enterprise Server. [2][5][6]

### How does Microsoft report GitHub Copilot in its SEC Form 10-K?

In Microsoft Corporation's Form 10-K for the fiscal year ended June 30, 2026, GitHub cloud services are included within the Intelligent Cloud segment under Server products and cloud services and within the Azure and other cloud services revenue growth metric. The Form 10-K describes GitHub as offering cloud and on-premises collaboration tools that incorporate AI and agent-based capabilities across the software development lifecycle, without reporting standalone GitHub Copilot revenue in those disclosures.
