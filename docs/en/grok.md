# Grok

> Developed by xAI (SpaceX Super Intelligence LLC), Grok spans from the open-weight 314-billion-parameter Grok-1 Mixture-of-Experts release (Apache 2.0) and Grok-2 (2024) to the late-2026 flagship Grok 4.7 (`grok-4.7`), which features a 500,000-token context window, a May 2026 knowledge cutoff, configurable encrypted reasoning, and API pricing of $2.00 per million input tokens and $6.00 per million output tokens. On October 12, 2026, xAI launched The X Subscription ($0 Free, $8 Plus, $30 Premium, $100 Super, and $200 Ultra per month), combining Grok, Grok Bot, Cursor coding agents, and X Premium into a single shared weekly AI usage pool.

Grok is a family of generative artificial intelligence models, developer APIs, and conversational and coding applications developed by xAI (operating in 2026 under SpaceX Super Intelligence LLC / SpaceXSI) and integrated across `grok.com`, mobile apps, the X social platform, and the Cursor coding environment. Anchored as of late 2026 by the flagship Grok 4.7 (`grok-4.7`) reasoning and coding model alongside dedicated Voice, Imagine image, and Imagine video generation models, Grok is offered to developers via the xAI Responses API and to consumers and teams through the unified X Subscription.

## Evolution from Grok-1 and Grok-2 to SpaceX Super Intelligence

Grok was created by xAI to provide conversational reasoning, coding assistance, and real-time information synthesis integrated with the X social network.[7][8] During its initial generation, xAI released the open-weight Grok-1 base checkpoint (`github.com/xai-org/grok-1` and `huggingface.co/xai-org/grok-1`) under the Apache 2.0 license with reference JAX inference code.[7] Grok-1 is a 314-billion-parameter Mixture-of-Experts (MoE) language model built with 64 transformer layers, 8 experts per layer with 2 experts activated per token, an embedding dimension of 6,144, 48 query attention heads and 8 key/value heads, rotary position embeddings (RoPE), a 131,072-token SentencePiece vocabulary, activation sharding and 8-bit quantization support, and an 8,192-token maximum sequence length.[7]

In August 2024, xAI launched Grok-2, followed on December 12, 2024, by an upgraded Grok-2 release (`grok-2-1212` and `grok-2-vision-1212`) that ran three times faster, rolled out free access on the X platform alongside real-time web search, inline source citations, a timeline "Grok button", and the Aurora autoregressive photorealistic image generator, and reduced API pricing to $2 per million input tokens and $10 per million output tokens.[8]

By 2026, xAI's developer documentation, news announcements, and pricing portal operate under the corporate entity SpaceX Super Intelligence LLC (branded as SpaceXSI, with social handles `@SpaceXSI` and `@grok`), while direct self-serve consumer and team subscriptions are sold exclusively through X Subscription Corp.[1][4][5] The product portfolio expanded beyond chat into a full suite comprising Grok Chat, Grok Build (agentic coding), Grok Bot (autonomous AI teammates), Grok Imagine (image and video generation), Grok Voice, and Grokipedia.[3][4]

## Grok 4.7 and the Multimodal Model Catalog

As of November 2026, Grok 4.7 (`grok-4.7`) is the flagship foundation model across the Grok platform and xAI API, recommended for all text, chat, and software engineering workloads.[1][2] Grok 4.7 features a 500,000-token context window, configurable reasoning effort, a May 2026 knowledge cutoff, and list pricing of $2.00 per million input tokens and $6.00 per million output tokens (a 40% output cost reduction compared with the $2/$10 pricing of Grok-2).[1][2][8]

Key technical behaviors of Grok 4.7 and the Grok 4.x API lineup include:[2][3]

- **Encrypted Reasoning Content**: On the xAI Responses API (`POST https://api.x.ai/v1/responses`), `grok-4.7` always returns `reasoning.encrypted_content` in its payload, even when the request's `include` parameter does not explicitly request it.[2]
- **Flexible Role Ordering and Parameter Rules**: Chat models support arbitrary ordering of `system`, `user`, and `assistant` roles in conversation contexts.[2] For `grok-4.20` and all newer models, `logprobs` and `top_logprobs` are unsupported and silently ignored if passed.[2]
- **Vision Input Constraints**: Image-capable Grok models accept `jpg`/`jpeg` and `png` files up to 20 MiB per image with no limit on the maximum number of images per request (within the token context window) and accept interleaved image and text prompts in any order.[2]
- **Explicit Real-Time Grounding**: By default, Grok API models have no access to current events after their May 2026 training cutoff unless the caller enables server-side search tools (Web Search, X Search, Collections RAG, Code Execution, or Remote MCP Tools).[1][2]

## xAI API Architecture, Cloud Integrations, and Rate Limit Tiers

The xAI developer platform exposes the modern Responses API (`https://api.x.ai/v1/responses`), an OpenAI-compatible REST interface, the native gRPC-based `xai_sdk` Python package, and official integrations with the Vercel AI SDK (`@ai-sdk/xai`), Google Cloud Vertex AI, and Microsoft Foundry.[1][3] Advanced enterprise API capabilities include Prompt Caching, Context Compaction, Priority Processing, Custom Moderation Controls, a Batch API, Deferred Completions, Async Requests, WebSocket Mode, mTLS Authentication, Regional Endpoints, and Output Watermarking.[1][3]

Every xAI API team is governed by per-model rate limits across two dimensions: requests per second (RPS) and tokens per minute (TPM) for language models, or concurrent sessions (CST) and RPS for voice endpoints.[3] A team's per-second request cap is derived from its per-minute budget (`RPM / 48`, with a minimum of 2 RPS) to prevent single-second burst exhaustion.[3] All prompt tokens (text, image, audio), completion tokens, reasoning tokens, and cached prompt tokens count toward the model's TPM limit.[3] Rate-limit tiers unlock automatically and permanently (never downgrading) based on cumulative API spend since January 1, 2026:[3]

## The X Subscription: Unification of Grok, Grok Bot, Cursor, and X Premium

Each paid tier provides a weekly-refreshing pool of Grok model usage shared across the Grok web/mobile apps, the Grok tab on X, Grok Bot, and Cursor, delivering at least twice as much coding usage with Grok models as the comparable legacy standalone Cursor plan (and 3x more coding usage on Team plans than older Cursor Teams).[4][5] Existing standalone SuperGrok, Cursor, and X Premium subscribers can optionally retain their legacy plans or switch to The X Subscription with an automatic prorated refund for unused time (except Apple App Store Cursor subscriptions, which must be cancelled directly through Apple).[4][6]

## Frequently asked questions

### What are the specifications and API prices of Grok 4.7?

Grok 4.7 (grok-4.7) is xAI's flagship language, coding, and reasoning model as of late 2026. It supports a 500,000-token context window, configurable reasoning effort (always returning reasoning.encrypted_content on the Responses API), a May 2026 knowledge cutoff, and unlimited image inputs up to 20 MiB per JPEG/PNG file. Standard API pricing is $2.00 per million input tokens and $6.00 per million output tokens. [2]

### What is included in The X Subscription announced in October 2026?

Introduced on October 12, 2026, The X Subscription bundles Grok (Chat, Voice, Imagine image/video generation, and Grok Build), Grok Bot AI teammates, the Cursor coding editor and cloud agents (including Origin code hosting and Bugbot AI code reviews), and X Premium into one plan with a shared weekly AI usage pool. Tiers are Free ($0), Plus ($8/month or $80/year), Premium ($30/month or $300/year, 4x Plus usage, replacing $90/month of separate SuperGrok, Cursor Pro, and X Premium+ plans), Super ($100/month or $1,000/year, 15x Plus usage), and Ultra ($200/month or $2,000/year, 50x Plus usage). [4]

### Does The X Subscription cover third-party models in Cursor or direct Grok API token charges?

No. The shared weekly usage pool on The X Subscription covers Grok models used across the Grok apps, X, Grok Bot (on Premium and above), and Cursor. Third-party models in Cursor remain available on Premium, Super, and Ultra plans, but are billed separately at API list prices from the first token via prepaid top-ups. Similarly, direct Grok API calls are billed separately at standard per-token API rates. [6]

### How do xAI API rate limit tiers work?

xAI API rate limits are enforced per model on requests per second (RPS, calculated as RPM / 48 with a minimum of 2) and tokens per minute (TPM, counting prompt, completion, reasoning, and cached tokens). Tiers unlock automatically and permanently based on cumulative spend since January 1, 2026: Tier 0 ($0), Tier 1 ($50), Tier 2 ($250), Tier 3 ($1,000), and Tier 4 ($5,000). For Grok 4.5, 4.6, and 4.7, limits scale from 150 RPS and 50M TPM at Tier 0 to 500 RPS and 100M TPM at Tier 4. [3]
