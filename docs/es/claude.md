Claude es un asistente de inteligencia artificial y una familia de modelos de lenguaje grande desarrollados por Anthropic, PBC, una corporación de beneficio público de Delaware con sede en San Francisco, California. Anthropic presentó públicamente Claude el 14 de marzo de 2023 mediante una interfaz de chat y una API para desarrolladores, y posteriormente amplió la línea de productos para incluir Claude Code para el desarrollo de software en terminal e IDE, Claude Cowork para flujos de trabajo de escritorio y la Claude Platform API. Claude está disponible mediante planes Free, Pro, Max, Ultra, Team, Enterprise y Education, a través de la API propia de Anthropic, y en Amazon Bedrock, Google Cloud y Microsoft Foundry.

## Descripción general, historial de lanzamiento y línea de productos de Claude

Claude es desarrollado por [Anthropic](https://mimirwiki.com/es/wiki/anthropic), PBC, una corporación de beneficio público de Delaware con oficinas ejecutivas principales en 548 Market Street, PMB 90375, San Francisco, California 94104.[1] Según la Enmienda n.º 3 del Formulario S-1 presentada ante [SEC EDGAR](https://mimirwiki.com/es/wiki/sec-edgar) el 17 de noviembre de 2026, Anthropic está dirigida por sus cofundadores Dario Amodei (director ejecutivo) y Daniela Amodei (presidenta).[1] Anthropic presentó públicamente Claude el 14 de marzo de 2023, tras una fase alfa cerrada con socios iniciales entre los que se incluían Notion, Quora (a través de Poe) y DuckDuckGo (para DuckAssist), junto con Juni Learning, Robin AI y AssemblyAI.[3]

En su lanzamiento de marzo de 2023, Claude se ofreció mediante una interfaz de chat y una API de consola para desarrolladores en dos versiones: Claude y una opción más ligera y de menor costo llamada Claude Instant.[3] Anthropic señaló que la versión inicial abordaba tareas como el resumen, la búsqueda, la redacción colaborativa, la respuesta a preguntas y la programación.[3]

Al 23 de noviembre de 2026, la descripción general de productos de Anthropic enumera un conjunto más amplio construido en torno a los modelos Claude, que incluye la aplicación de chat Claude en web, escritorio, iOS y Android, Claude Code, Claude Cowork, Claude Duet (en vista previa de investigación con lista de espera), Claude Platform, Claude Tag y ofertas especializadas denominadas Claude Security y Claude Science.[6][7] Entre las capacidades documentadas en las aplicaciones de Claude se encuentran Artifacts, Design, Docs, Slides, Data, Sheets and Whiteboards (beta), Connectors, Plugins, Skills, Extensions, Voice mode, búsqueda web, Research, programación de tareas, Claude in Chrome, Claude for Google Workspace y Claude for Microsoft 365.[6][7] En septiembre de 2026, Anthropic comenzó a fusionar Claude Cowork y Claude.ai en una sola aplicación para que los usuarios puedan alternar entre consultas de chat y tareas de escritorio de varios pasos dentro de una misma conversación.[1]

En Claude Platform Docs, Anthropic designa Claude Fable 5.2 para razonamiento exigente y trabajo agéntico de largo horizonte, Claude Opus 5.5 para cargas de trabajo generales y programación agéntica y trabajo de conocimiento de larga duración, Claude Sonnet 5.5 para una combinación de velocidad y capacidad, y Claude Haiku 5.5 para tareas de alto volumen sensibles a la latencia como clasificación, extracción y enrutamiento.[4] Para los cuatro modelos, tanto el corte de conocimiento confiable como el corte de datos de entrenamiento figuran en junio de 2026.[4]

Al 23 de noviembre de 2026, Claude Platform Docs también enumera modelos adicionales y anteriores junto a los cuatro actuales: Claude Mythos 5.2, Claude Fable 5.1 y 5, Claude Mythos 5.1 y 5, Claude Opus 5, 4.8, 4.7, 4.6, 4.5, 4.1 y 4, Claude Sonnet 5, 4.6, 4.5 y 4, y Claude Haiku 4.5.[4] Los modelos anteriores, incluidos Claude Opus 4.5, Claude Sonnet 4.5, Claude Sonnet 4 y Claude Haiku 4.5, tienen una ventana de contexto de 200 000 tokens y una salida máxima de 64 000 tokens, mientras que Claude Opus 4.1 y Claude Opus 4 tienen una ventana de contexto de 200 000 tokens y una salida máxima de 32 000 tokens.[4]

Los desarrolladores pueden inspeccionar las especificaciones de los modelos de forma programática mediante el endpoint `GET /v1/models`, que filtra por etapa del ciclo de vida (`active`, `deprecated` o `retired`) y devuelve `max_input_tokens`, `max_tokens`, `line` y un objeto `capabilities` que abarca configuraciones como `thinking.types.disabled`, `thinking.types.between_tools`, `server_tools` (búsqueda web y ejecución de código) y llamadas programáticas a herramientas.[4] El Formulario S-1/A-3 de Anthropic también define capacidades de Claude como el uso de computadora (observar e interactuar con interfaces gráficas de usuario haciendo clic, escribiendo y navegando por aplicaciones) y el pensamiento intercalado (insertar pasos discretos de razonamiento entre llamadas consecutivas a herramientas dentro de una misma respuesta).[1]

El almacenamiento en caché de prompts aplica multiplicadores fijos a los precios base de entrada: 1.25x para escrituras en caché de 5 minutos y 2x para escrituras en caché de 1 hora, con multiplicadores de lectura de caché de 0.025x en Fable 5.2, Mythos 5.2, Fable 5.1 y Mythos 5.1, 0.05x en Opus 5.5 y Sonnet 5.5, y 0.1x en todos los demás modelos.[5] La Batch API ofrece un descuento del 50 % tanto en los tokens de entrada como en los de salida para solicitudes asíncronas.[5] El modo rápido (Fast mode) ofrece hasta 2.5x más tokens de salida por segundo al doble del precio estándar en modelos compatibles ($16/$80 por MTok para Fable 5.2 y Mythos 5.2, $8/$40 por MTok para Opus 5.5 y $10/$50 por MTok para Opus 5 y Opus 4.8) y no se puede combinar con la Batch API.[5]

Para Claude 4.6 y modelos posteriores, seleccionar inferencia exclusiva en Estados Unidos mediante el parámetro `inference_geo: "us"` aplica un multiplicador de 1.1x a todas las categorías de precios de tokens en la API propia, Claude Platform on AWS, las implementaciones de Google Cloud administradas por Anthropic y las implementaciones Azure US Data Zone Standard en Microsoft Foundry.[5] Anthropic documenta que Claude 4.7 y modelos posteriores (junto con Claude Mythos Preview) utilizan un tokenizador más reciente que produce aproximadamente un 30 % más de tokens para el mismo texto en comparación con Claude Sonnet 4.6 y modelos anteriores.[5] Entre los modelos adicionales listados el 23 de noviembre de 2026, los precios base de entrada y salida por MTok son de $8/$40 para Claude Mythos 5.2, $10/$50 para Fable 5.1, Fable 5, Mythos 5.1 y Mythos 5, $5/$25 para Opus 5 hasta Opus 4.5, $15/$75 para Opus 4.1 y Opus 4, $2/$10 para Sonnet 5, $3/$15 para Sonnet 4.6 hasta Sonnet 4 y $1/$5 para Haiku 4.5.[5]

Además de las tarifas por token, `claude.com/pricing` enumera cargos separados para tres funciones de Claude Platform al 23 de noviembre de 2026: Managed Agents a $0.08 por hora de sesión de ejecución activa (más tarifas estándar por token), búsqueda web a $10 por cada 1000 búsquedas (sin incluir el consumo de tokens) y ejecución de código Python en entorno aislado con 50 horas gratuitas al día por organización seguidas de $0.05 por hora por contenedor.[6]

Al 23 de noviembre de 2026, la API de Claude aplica límites de gasto a nivel de organización y límites de tasa medidos en solicitudes por minuto (RPM), tokens de entrada por minuto (ITPM) y tokens de salida por minuto (OTPM), devolviendo respuestas HTTP 429 cuando se superan.[12] Los topes de gasto mensual por nivel de uso estándar son de $500 USD en Start, $1,000 USD en Build y $200,000 USD en Scale, mientras que las cuentas nuevas pueden comenzar en un nivel Evaluation; los límites predeterminados de ITPM cuentan únicamente `input_tokens` sin caché y `cache_creation_input_tokens`, excluyendo `cache_read_input_tokens`, y Managed Agents aplica 300 RPM en endpoints de creación y 1200 RPM en endpoints de lectura.[12] Para el listado de direcciones permitidas en cortafuegos al 23 de noviembre de 2026, Anthropic documenta rangos IP entrantes fijos de `160.79.104.0/23`, `153.61.224.0/22` e IPv6 `2607:6bc0::/48`, y rangos IPv4 salientes de `160.79.104.0/21` y `153.61.208.0/20` para solicitudes salientes como llamadas a herramientas MCP, búsqueda web y recuperación web.[13]

## Claude Code, Claude Cowork y disponibilidad en plataformas en la nube

Claude Code es la herramienta de programación agéntica de Anthropic, lanzada por primera vez como vista previa de investigación en febrero de 2025.[1][8] Según el Formulario S-1/A-3 de Anthropic y el repositorio oficial de GitHub (`anthropics/claude-code`), Claude Code se ejecuta en la terminal, en IDE o mediante menciones `@claude` en GitHub, inspeccionando bases de código, planificando, escribiendo, probando y depurando código, y gestionando flujos de trabajo de Git mediante comandos en lenguaje natural en un entorno de ejecución local persistente o aislado en la nube.[1][8] El Formulario S-1/A-3 de Anthropic señala que ingenieros de la NASA utilizaron Claude Code para planificar y escribir comandos de navegación para el róver Mars Perseverance.[1]

Al 23 de noviembre de 2026, el repositorio público `anthropics/claude-code` en GitHub registraba 156.8k estrellas, 25.1k bifurcaciones (forks) y 1110 confirmaciones (commits).[8] Los métodos de instalación incluidos en el archivo README del repositorio al 23 de noviembre de 2026 comprenden el script de shell (`curl -fsSL https://claude.ai/install.sh | bash`) y el cask de Homebrew (`brew install --cask claude-code`) en macOS y Linux, así como el script de PowerShell (`irm https://claude.ai/install.ps1 | iex`) y WinGet (`winget install Anthropic.ClaudeCode`) en Windows, mientras que la instalación mediante npm (`@anthropic-ai/claude-code`) figura como obsoleta.[8] Al extender esta arquitectura agéntica al trabajo de conocimiento de escritorio, Anthropic lanzó Claude Cowork como vista previa de investigación en enero de 2026 para leer archivos, navegar por aplicaciones y ejecutar flujos de trabajo de varios pasos en el escritorio del usuario, y comenzó a fusionar Claude Cowork con Claude.ai en septiembre de 2026.[1]

Fuera de la API propia de Anthropic, los modelos Claude se distribuyen a través de importantes plataformas en la nube.[4][5] En Amazon Web Services, los modelos Claude están disponibles mediante Amazon Bedrock (que enumera lanzamientos actuales como Claude Fable 5.2, Opus 5.5, Sonnet 5.5 y Haiku 5.5 y se integra con Amazon Bedrock AgentCore para agentes autónomos que se ejecutan hasta ocho horas) y mediante Claude Platform on AWS.[4][5][9] En Google Cloud, los modelos Claude se ofrecen mediante Model Garden en Gemini Enterprise Agent Platform tanto en implementaciones administradas por Google como en implementaciones administradas por Anthropic, abarcando Fable 5 a 5.2, Opus 4.5 a 5.5, Sonnet 4.5 a 5.5 y Haiku 4.5 y 5.5 al 23 de noviembre de 2026.[4][5][10] Los modelos Claude también están disponibles en Azure mediante Microsoft Foundry.[4][5]

Los modelos de facturación en la nube varían según el canal al 23 de noviembre de 2026.[5] En plataformas operadas por socios (Amazon Bedrock y Claude Models administrados por Google en Google Cloud), el proveedor de la nube factura directamente a los clientes, y los endpoints regionales o multirregión incluyen un recargo del 10 % respecto a los endpoints globales para Claude 4.5 y modelos posteriores.[5] En plataformas de mercado operadas por Anthropic (Claude Platform on AWS mediante AWS Marketplace y Claude en Microsoft Foundry mediante Azure Marketplace), Anthropic calcula el consumo de tokens en dólares estadounidenses según tarifas estándar, convierte el total en Claude Consumption Units (CCU) a $0.01 USD por CCU, informa las CCU cada hora y factura mensualmente a mes vencido.[5]

## Entrenamiento de Claude con Constitutional AI y compatibilidad con Model Context Protocol

Los modelos Claude se alinean mediante Constitutional AI, un método de entrenamiento descrito por Yuntao Bai y 50 coautores en Anthropic en el artículo de arXiv del 15 de diciembre de 2022 titulado "Constitutional AI: Harmlessness from AI Feedback".[2][9] Con este método, la supervisión humana se proporciona a través de una lista escrita de reglas o principios, y el entrenamiento se lleva a cabo en dos etapas.[2] En la etapa de aprendizaje supervisado, un modelo inicial genera salidas, critica y revisa dichas salidas frente a los principios escritos y se ajusta finamente con las respuestas revisadas.[2] En la etapa de aprendizaje por refuerzo, denominada aprendizaje por refuerzo a partir de retroalimentación de IA (RLAIF), un modelo de IA evalúa pares de respuestas muestreadas para crear un conjunto de datos de preferencias, se entrena un modelo de preferencias con ese conjunto de datos y el aprendizaje por refuerzo utiliza ese modelo de preferencias como señal de recompensa.[2] Ambas etapas pueden emplear razonamiento en cadena de pensamiento para que el asistente explique sus objeciones al responder consultas perjudiciales.[2]

En el Formulario S-1/A-3 de Anthropic presentado el 17 de noviembre de 2026, Constitutional AI se define como el entrenamiento de modelos según un conjunto de principios escritos denominados la constitución de Claude, organizados en torno a cuatro prioridades: ser ampliamente seguro, ampliamente ético, conforme con las directrices de Anthropic y genuinamente útil.[1] Mediante este proceso, los modelos evalúan, critican y revisan sus propias respuestas frente a principios escritos auditables.[1]

Claude también se conecta con herramientas y sistemas de datos externos a través del [Model Context Protocol](https://mimirwiki.com/es/wiki/model-context-protocol) (MCP), un estándar abierto creado en Anthropic por David Soria Parra y Justin Spahr-Summers y publicado como código abierto el 25 de noviembre de 2024.[11] MCP define una arquitectura cliente-servidor en la que las fuentes de datos exponen acceso mediante servidores MCP y las aplicaciones de IA actúan como clientes MCP para mantener conexiones bidireccionales.[11] En el lanzamiento, Anthropic publicó la especificación y los SDK de MCP, incorporó compatibilidad con servidores MCP locales en las aplicaciones de Claude Desktop en todos los planes de Claude.ai y publicó servidores MCP preconstruidos de código abierto para sistemas como Google Drive, Slack, GitHub, Git, Postgres y Puppeteer.[11] El anuncio de lanzamiento de Anthropic citó a Block y Apollo como adoptantes iniciales que integraron MCP, junto con empresas de herramientas para desarrolladores como Zed, Replit, Codeium y Sourcegraph que trabajaban con el protocolo.[11]

Los cuatro modelos ofrecen una ventana de contexto de 1 millón de tokens, hasta 128 000 tokens de salida, pensamiento adaptativo, visión, uso de herramientas y una fecha de corte de conocimiento de junio de 2026. [4]

### ¿Cuánto cuestan los planes de suscripción de Claude?

Al 23 de noviembre de 2026, Claude ofrece cuatro niveles individuales: Free ($0), Pro ($17 al mes facturados anualmente a $200 por adelantado, o $20 facturados mensualmente), Max ($100 al mes) y Ultra ($200 al mes). Los planes Team para entre 2 y 150 puestos figuran con puestos Standard a $20 por puesto al mes anualmente ($25 mensuales) y puestos Premium a $100 por puesto al mes anualmente ($125 mensuales), mientras que Enterprise comienza en $20 por puesto al mes facturados anualmente con un mínimo de 20 puestos más el consumo facturado según tarifas de la API. [6]

### ¿Cuáles son los precios por token de la API de Claude?

Al 23 de noviembre de 2026, los precios base de la API de Claude por millón de tokens de entrada y salida son de $8 y $40 para Claude Fable 5.2, $4 y $20 para Claude Opus 5.5, y $2 y $10 para Claude Sonnet 5.5. Claude Haiku 5.5 tiene un precio de $0.10 de entrada y $0.50 de salida por millón de tokens para prompts de hasta 100 000 tokens, y de $0.50 de entrada y $2.50 de salida para prompts que superen los 100 000 tokens. La Batch API aplica un descuento del 50 % sobre las tarifas de tokens de entrada y salida. [5]

### ¿Qué es Claude Code y qué planes lo incluyen?

Claude Code es la herramienta de programación agéntica de Anthropic, lanzada como vista previa de investigación en febrero de 2025, que se ejecuta en una terminal, un IDE o mediante menciones @claude en GitHub para planificar, escribir, probar y depurar código y gestionar flujos de trabajo de Git. Al 23 de noviembre de 2026, Claude Code está incluido en los planes Pro, Max, Ultra, Team y Enterprise, y no está incluido en el plan Free. [1][6][8]

### ¿Qué plataformas en la nube ofrecen los modelos Claude?

Al 23 de noviembre de 2026, los modelos Claude están disponibles en Amazon Web Services mediante Amazon Bedrock y Claude Platform on AWS, en Google Cloud mediante Model Garden en Gemini Enterprise Agent Platform en implementaciones administradas por Google y administradas por Anthropic, y en Azure mediante Microsoft Foundry. En Amazon Bedrock y en las implementaciones de Google Cloud administradas por Google, los endpoints regionales o multirregión conllevan un recargo del 10 % respecto a los endpoints globales para Claude 4.5 y modelos posteriores. [4][5][9][10]

### ¿Cómo se relacionan Constitutional AI y el Model Context Protocol con Claude?

Constitutional AI, presentado por investigadores de Anthropic en diciembre de 2022, entrena a los modelos Claude para evaluar, criticar y revisar sus propias salidas según un conjunto escrito de principios mediante aprendizaje supervisado y aprendizaje por refuerzo a partir de retroalimentación de IA (RLAIF). El Model Context Protocol (MCP), publicado como código abierto por Anthropic el 25 de noviembre de 2024, es un estándar abierto cliente-servidor que conecta las aplicaciones de Claude, incluido Claude Desktop, con fuentes de datos y herramientas externas. [1][2][11]
