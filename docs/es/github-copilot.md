# GitHub Copilot

> GitHub Copilot es un asistente de programación y plataforma de agentes de inteligencia artificial desarrollado por GitHub, cuyos servicios en la nube figuran en el segmento Intelligent Cloud de Microsoft Corporation. Lanzado en vista previa técnica el 29 de junio de 2021 y con disponibilidad general el 21 de junio de 2022, opera en IDE, terminales, aplicaciones de escritorio y github.com. GitHub Copilot es un asistente de programación y plataforma de agentes de inteligencia artificial desarrollado por GitHub, cuyas ofertas en la nube y locales se informan dentro del segmento Intelligent Cloud de Microsoft Corporation. GitHub presentó GitHub Copilot en una vista previa técnica limitada el 29 de junio de 2021 utilizando OpenAI Codex, lo puso a disposición general para desarrolladores individuales el 21 de junio de 2022 y lanzó el plan gratuito GitHub Copilot Free el 18 de diciembre de 2024. ## Historial de lanzamiento de GitHub Copilot y contexto de informes de Microsoft

GitHub Copilot fue presentado por GitHub en una vista previa técnica limitada el 29 de junio de 2021, desarrollado en colaboración con [OpenAI](https://mimirwiki.com/es/wiki/openai) e impulsado por [OpenAI Codex](https://mimirwiki.com/es/wiki/openai-codex).[7] En el momento de su lanzamiento, GitHub describió Copilot como un programador en pareja de IA que tomaba contexto del código abierto para sugerir líneas o funciones completas, entrenado con un conjunto de datos con una alta concentración de código fuente público y compatible con múltiples lenguajes, especialmente Python, JavaScript, TypeScript, Ruby y Go.[7]

El 21 de junio de 2022, GitHub puso GitHub Copilot a disposición general para todos los desarrolladores individuales como una extensión para editores a un precio de $10 USD al mes o $100 USD al año, con una prueba gratuita y acceso sin costo para estudiantes verificados y mantenedores de proyectos populares de código abierto.[8] El 18 de diciembre de 2024, Thomas Dohmke (director ejecutivo de GitHub de 2021 a 2025) anunció GitHub Copilot Free, integrado en Visual Studio Code y accesible desde el panel de control de GitHub, tras alcanzar GitHub los 150 millones de desarrolladores en la plataforma.[9] En su lanzamiento, Copilot Free ofrecía 2000 completaciones de código y 50 mensajes de chat al mes, admitía [Claude](https://mimirwiki.com/es/wiki/claude) 3.5 Sonnet de [Anthropic](https://mimirwiki.com/es/wiki/anthropic) y GPT-4o de OpenAI, habilitaba ediciones en múltiples archivos y agentes de terceros, y mantenía sin cambios el acceso gratuito e ilimitado a Copilot Pro para estudiantes, educadores y mantenedores de código abierto.[9]

En el Formulario 10-K de Microsoft Corporation correspondiente al ejercicio fiscal finalizado el 30 de junio de 2026 (SEC Central Index Key 0000789019 en [SEC EDGAR](https://mimirwiki.com/es/wiki/sec-edgar)), se describe a GitHub como un proveedor de soluciones en la nube y locales para que los desarrolladores gestionen código e incorporen herramientas de IA y basadas en agentes a lo largo del ciclo de vida del desarrollo de software.[1] Microsoft informa los servicios en la nube de GitHub dentro de su segmento Intelligent Cloud bajo productos de servidor y servicios en la nube, y agrupa los ingresos de servicios en la nube de GitHub dentro de la métrica de crecimiento de ingresos de Azure y otros servicios en la nube sin divulgar por separado los ingresos independientes de GitHub Copilot en esos extractos.[1] Para el ejercicio fiscal finalizado el 30 de junio de 2026, Microsoft informó los siguientes resultados consolidados en su Formulario 10-K.[1]

## Planes y precios de GitHub Copilot

## GitHub AI Credits y modelo de facturación de GitHub Copilot

GitHub Copilot utiliza GitHub AI Credits para medir el uso interactivo y agéntico de IA en todos los planes al 23 de noviembre de 2026, con un valor de $0.01 USD por 1 AI credit.[6] El chat, el modo agente, la revisión de código, Copilot en la nube, Copilot CLI y la aplicación Copilot consumen AI credits, y el costo en créditos de cada interacción varía según el modelo seleccionado y la complejidad de la tarea.[5][6] Las completaciones de código en línea y las sugerencias de próxima edición no consumen AI credits y siguen siendo ilimitadas en los planes de pago, incluso cuando un usuario de una organización tiene un presupuesto de $0 USD o alcanza un límite de gasto establecido.[3][6]

En los planes individuales de pago al 23 de noviembre de 2026, los créditos mensuales totales combinan una asignación base fija equivalente a la tarifa mensual del plan ($10 para Pro, $39 para Pro+ y $100 para Max) con una asignación flexible variable ($5 para Pro, $31 para Pro+ y $100 para Max) que GitHub señala que puede cambiar con el tiempo.[5] Cuando los usuarios agotan su asignación mensual, pueden esperar al siguiente reinicio mensual, cambiar a modelos ligeros que consumen menos créditos por interacción o establecer un presupuesto en dólares para uso adicional de pago por uso a $0.01 USD por crédito ($10 cubren 1000 créditos); la compra de créditos adicionales está excluida en el plan Free.[5][6] El seguimiento presupuestario en la configuración de Copilot emite alertas de uso al 75%, 90% y 100% de cualquier presupuesto configurado.[6]

Para organizaciones y empresas, las licencias de Copilot Business y Copilot Enterprise aportan sus asignaciones mensuales de créditos a un fondo compartido para toda la organización, y el uso que supere dicho fondo se factura por separado cuando los administradores permiten consumos excedentes de pago.[3][5][6] Si los administradores no permiten el uso adicional de pago, Copilot se pausa hasta el siguiente ciclo de facturación.[6] En el plan Copilot access, el uso medido se factura desde el primer uso sin una asignación incluida.[3] Cada puesto de Copilot representa una licencia para un usuario y debe asignarse incluso cuando el puesto tenga un cargo incremental de $0; en Copilot access y Copilot Business, los propietarios de empresas pueden asignar puestos directamente a personas o a equipos empresariales para que cada miembro del equipo reciba un puesto.[3] Las solicitudes de Copilot con residencia de datos y cumplimiento de FedRAMP conllevan un aumento del 10% en el multiplicador de modelo.[3]

Junto con la selección manual de modelos, GitHub Copilot incluye Copilot Fusion para el enrutamiento automático de modelos al 23 de noviembre de 2026.[5][6] Fusion Standard (incluido en Free, Pro, Pro+ y Max) selecciona un modelo por tarea para el trabajo cotidiano, y Fusion Fast (incluido en Free, Pro, Pro+ y Max) funciona únicamente en el chat en línea de Visual Studio Code y no es directamente seleccionable por los usuarios.[5] Fusion High (incluido en Pro+ y Max) está orientado a cambios en múltiples archivos o correcciones de errores complejas que pueden requerir llamadas adicionales a modelos, y Fusion Max (incluido en Pro+ y Max) se dirige a tareas que exigen un razonamiento y análisis más profundos.[5]

## Superficies, compatibilidad con IDE y capacidades de agente de GitHub Copilot

GitHub Copilot opera en editores, terminales, software de escritorio, interfaces web y aplicaciones de mensajería al 23 de noviembre de 2026, lo que permite que una sesión iniciada en una superficie continúe en otra.[5][6] Los editores y entornos IDE compatibles enumerados por GitHub incluyen Visual Studio Code, Visual Studio, los IDE de JetBrains, Xcode, Vim, Neovim, Zed, Eclipse, Raycast y SQL Server Management Studio.[5][6] Más allá de los editores, GitHub Copilot funciona en la terminal mediante Copilot CLI, en la aplicación de escritorio de GitHub Copilot (incluidas compilaciones para macOS con Apple Silicon), en github.com, en GitHub Mobile, en Slack y en Microsoft Teams.[5][6]

Las capacidades principales de programación y agentes enumeradas por GitHub al 23 de noviembre de 2026 incluyen las siguientes.[5][6]

- **Sugerencias en línea y sugerencias de próxima edición**: Completaciones de código en tiempo real en lenguajes presentes en repositorios públicos, con un límite de 2000 completaciones al mes en Free e ilimitadas en planes de pago.[5][6]
- **Modo agente en IDE**: Disponible en Free, Pro, Pro+ y Max en Visual Studio Code, Visual Studio, los IDE de JetBrains, Eclipse y Xcode.[5]
- **Copilot en la nube**: Disponible en planes de pago para investigar, planificar y escribir código con o sin una solicitud de incorporación de cambios (pull request), iniciar y supervisar trabajo desde incidencias, solicitudes de incorporación de cambios, editores, el panel de agentes o herramientas de gestión de proyectos de terceros, y ejecutar sesiones en paralelo.[5][6]
- **Copilot CLI**: Disponible en todos los planes para trabajar desde la terminal, delegar tareas a agentes de programación, realizar y confirmar cambios de código de forma local o en GitHub y ejecutarse en modo programático.[2][5]
- **Revisión de código y modernización**: Disponible en Pro y planes superiores para revisiones de solicitudes de incorporación de cambios en GitHub, revisiones de diferencias de archivos locales en editores de código, instrucciones de revisión personalizadas mediante `instructions.md` y modernización de aplicaciones para Java y .NET.[5][6]
- **Automatizaciones y agentes de terceros**: Las tareas reutilizables de agentes pueden ejecutarse bajo demanda, de forma programada o a partir de disparadores compatibles, y los planes compatibles pueden delegar tareas a agentes de programación de terceros, incluidos Claude de Anthropic y [OpenAI Codex](https://mimirwiki.com/es/wiki/openai-codex).[5][6]

Para personalización y acceso a herramientas externas, GitHub Copilot admite instrucciones personalizadas, agentes personalizados, habilidades de agentes, Copilot Spaces, Copilot Connectors, complementos y servidores del [Model Context Protocol](https://mimirwiki.com/es/wiki/model-context-protocol) (MCP) tanto en el modo agente en IDE como en Copilot en la nube.[5][6]

## Filtrado de contenido, privacidad y gobernanza empresarial de GitHub Copilot

GitHub Copilot aplica filtrado de contenido en todos los modelos de IA predeterminados al 23 de noviembre de 2026, dirigiendo tanto las indicaciones (prompts) de entrada como las completaciones de salida a través de filtros para contenido dañino, ofensivo o fuera de tema.[4] Cuando está habilitado, GitHub Copilot también ejecuta un filtro de coincidencia de código público con referencia de código, que figura como incluido en los planes Free, Pro, Pro+ y Max.[4][5]

En sus preguntas frecuentes sobre privacidad del producto al 23 de noviembre de 2026, GitHub afirma que GitHub Copilot procesa cuatro categorías de datos personales según la superficie cliente y la función utilizada.[6]

- **Datos de interacción del usuario (User Engagement Data)**: Identificadores seudónimos registrados durante las interacciones, incluidas completaciones aceptadas o descartadas, mensajes de error, registros del sistema y métricas de uso del producto.[6]
- **Indicaciones (Prompts)**: Entradas de chat o código junto con el contexto circundante enviadas para generar sugerencias.[6]
- **Sugerencias (Suggestions)**: Líneas de código o respuestas de chat generadas por IA devueltas a partir de las indicaciones.[6]
- **Datos de comentarios (Feedback Data)**: Comentarios del usuario en tiempo real como reacciones de pulgar arriba o pulgar abajo, comentarios opcionales y comentarios de soporte.[6]

Para organizaciones y empresas, Copilot Business y Copilot Enterprise añaden gestión centralizada de puestos, controles de políticas de Copilot, fondos compartidos de créditos y límites de gasto para administradores que determinan si se permite el uso excedente.[2][3][6] Los planes empresariales también abarcan capacidades excluidas de los planes individuales, como autenticación SAML SSO, gestión de usuarios en github.com, métricas de uso de la organización, seguridad de nivel empresarial e indemnización de propiedad intelectual, mientras que los registros de auditoría figuran a partir de Pro+.[5] Las organizaciones que requieren procesamiento de solicitudes con residencia de datos o cumplimiento de FedRAMP incurren en un aumento del 10% en el multiplicador de modelo en dichas solicitudes.[3]

## Preguntas frecuentes

### ¿Cuáles son los planes y precios de GitHub Copilot?

Al 23 de noviembre de 2026, GitHub ofrece cinco planes individuales: Free ($0), Student ($0 para estudiantes verificados), Pro ($10 USD al mes), Pro+ ($39 USD al mes) y Max ($100 USD al mes). Para organizaciones y empresas, GitHub ofrece Copilot Business ($19 USD por puesto al mes), Copilot Enterprise ($39 USD por puesto al mes) y Copilot access ($0 para usuarios con licencia de GitHub Enterprise Cloud o $10 USD por usuario al mes para Copilot Standalone, con el uso medido facturado por separado). [2][3][5]

### ¿Cómo funcionan los GitHub AI Credits en GitHub Copilot?

Al 23 de noviembre de 2026, un GitHub AI Credit equivale a $0.01 USD, y los créditos cubren el uso de chat, el modo agente, la revisión de código, Copilot en la nube, Copilot CLI y la aplicación Copilot según el modelo elegido y la complejidad de la tarea. Las completaciones de código en línea y las sugerencias de próxima edición no consumen créditos y siguen siendo ilimitadas en los planes de pago. Los puestos de Business y Enterprise aportan créditos a un fondo compartido de la organización, y los presupuestos opcionales de pago por uso emiten alertas al 75%, 90% y 100%. [3][5][6]

### ¿Qué modelos de IA admite GitHub Copilot?

Al 23 de noviembre de 2026, GitHub Copilot admite modelos de OpenAI (series GPT-5 y GPT-6), Anthropic (series Claude Fable, Haiku, Sonnet y Opus), Google (series Gemini 3.7, 3.8 y Gemini 4), Microsoft (serie MAI Code), xAI (Grok 4.5 a 4.7) y Kimi (Kimi K3). Los usuarios pueden dejar que Copilot Fusion enrute las tareas automáticamente, seleccionar un modelo específico, conectar proveedores en la nube con su propia clave API o ejecutar modelos locales mediante Ollama y Foundry Local. [4][5][6]

### ¿Qué incluye GitHub Copilot Free?

Al 23 de noviembre de 2026, GitHub Copilot Free cuesta $0 sin necesidad de tarjeta de crédito e incluye 2000 completaciones de código en línea al mes, uso limitado de chat y agentes, Copilot CLI, la aplicación Copilot, Copilot Spaces, integración con servidores del Model Context Protocol en el modo agente, Copilot Fusion Standard y soporte comunitario. Excluye la revisión de código, Copilot en la nube, la creación de solicitudes de incorporación de cambios (pull requests) por agentes asignados y la compra de créditos adicionales. [2][5][6][9]

### ¿Qué IDE y plataformas son compatibles con GitHub Copilot?

Al 23 de noviembre de 2026, GitHub Copilot está disponible en Visual Studio Code, Visual Studio, los IDE de JetBrains, Xcode, Vim, Neovim, Zed, Eclipse, Raycast y SQL Server Management Studio. También funciona en la terminal mediante Copilot CLI, en la aplicación de escritorio de GitHub Copilot, en github.com, en GitHub Mobile, en Slack y en Microsoft Teams, y no está disponible para GitHub Enterprise Server. [2][5][6]

### ¿Cómo informa Microsoft sobre GitHub Copilot en su Formulario 10-K ante la SEC?

En el Formulario 10-K de Microsoft Corporation correspondiente al ejercicio fiscal finalizado el 30 de junio de 2026, los servicios en la nube de GitHub se incluyen dentro del segmento Intelligent Cloud bajo productos de servidor y servicios en la nube, así como dentro de la métrica de crecimiento de ingresos de Azure y otros servicios en la nube. El Formulario 10-K describe a GitHub como un proveedor de herramientas de colaboración en la nube y locales que incorporan capacidades de IA y basadas en agentes a lo largo del ciclo de vida del desarrollo de software, sin desglosar los ingresos independientes de GitHub Copilot en dichas declaraciones. [1]

- Al 23 de noviembre de 2026, un GitHub AI Credit equivale a $0.01 USD, y las completaciones de código en línea y las sugerencias de próxima edición no consumen créditos en los planes de pago. [3][6]
- Al 23 de noviembre de 2026, GitHub Copilot admite modelos de OpenAI, Anthropic, Google, Microsoft, xAI y Kimi, así como proveedores en la nube con clave API propia y modelos locales mediante Ollama y Foundry Local. [4][5][6]
- El Formulario 10-K de Microsoft Corporation correspondiente al ejercicio fiscal finalizado el 30 de junio de 2026 incluye los servicios en la nube de GitHub dentro de la categoría de productos de servidor y servicios en la nube del segmento Intelligent Cloud. [1]
